# Полные альтернативы и проверка повреждённых оригиналов

11 ноября 2026 года повторно проверены два прежних JPEG: `thematic-exhibition-altay` и `open-day-altay`. Старые байты сохранены неизменными. Первоначальная передача содержала отдельный supplemental manifest; при последующей интеграции проверенные записи добавлены в основной реестр с явными родителями публикации.

Оба исходных HTTP URL возвращают **ровно81920 байт**, с прежними SHA. Запрос оставшегося диапазона `bytes=81920-` возвращает **416 / Content-Range: bytes */81920**. На этих адресах сервер не хранит доступного продолжения. HTTPS-попытки вернули 503. Это наблюдение доступного origin-ответа; полный оригинал того же события не восстановлен.

Найдены два **других**, полностью декодируемых официальных изображения:

| Изображение | Источник | Полнота и назначение |
|---|---|---|
| Посетитель с архивным документом в читальном зале | [Страница читального зала1338](http://e-arhiv.vko.gov.kz/ru/Page/Index/1338) | 448×336,29953 байта. Полный официальный исходник; для карточки читального зала/услуг. Дата съёмки не указана, разрешение не увеличено |
| Визит сотрудников филиала Алтай ко Дню пожилого человека | [Новость52814](http://e-arhiv.vko.gov.kz/ru/Page/Index/52814) | 1280×720,108065 байт; событие1 октября 2026. Только этот исторический социальный контекст, не замена снимка другого события |

[Supplemental manifest](supplemental-manifest.json) содержит оригинальные байты, размеры, SHA, снимки страниц, alt/подписи RU/KK/EN и правила применения. [REPORT.json](REPORT.json) сохраняет безопасные HTTP-метаданные и точные результаты попыток.

Оба выбранных файла прошли **полный** строгий разбор `sharp({failOn:'warning'}).raw().toBuffer()` и просмотр `view_image`. Они не перекодированы и не дорисованы. Это новые источники, а не исправление старых фотографий и не разрешение приписать им чужое событие. Для сайта использовать существующий процесс проверки/публикации CMS-вложений. Фотограф в источниках не назван; свободная лицензия не выдумана.

## Текущее решение после интеграции PR5

[PR #5](https://github.com/Almzhn09/ALEteam/pull/5) подтверждён GitHub как **MERGED**, merge-коммит **`6a55d80`**. Текущий загрузчик выбирает родителя отдельно для каждой фотографии и сохраняет проверки binding/outputHash, публикации, ручного отзыва и незавершённой работы редактора.

| Источник | Публикация и контекст |
|---|---|
| `archive-next-generation-ridder` | Полный исходник опубликован к `history-1/ru`; дата проекта18 сентября 2026 сохранена |
| `reading-room-researcher` | Полное фото опубликовано к `reference-reading-room-info/ru`, материал `archive-reading-room-info`, namespace `real-content-20261111`. Дата съёмки не указана, оригинал 448×336 не увеличен до выдуманного высокого разрешения |
| `elderly-day-altay-2026` | Полный источник готов, но остаётся **`context_required`**. Это социальный визит1 октября 2026 из новости 52814; подходящий событийный родитель автоматически не создаётся. Не показывается как читальный зал или чужое событие |
| Два прежних повреждённых JPEG | Сохранены с прежними SHA, не объявлены восстановленными и остаются `incomplete_source` |

`decoderValidation` использует контракт PR5 (`checked`, `status: complete_decode`, `tool`). Сохранены поля загрузчика: `origin`, `path`, `bytes`, `sha256`, `caption`, `sourceImageUrl`, `sourceUrl`; размеры и alt доступны клиентскому реестру, `localized` — RU/KK/EN. Полный новый снимок не получает ID повреждённого снимка и не подменяет его дату/событие.

**Сетевой контекст:** ранний отчёт PR5 фиксировал403 и ожидание доступа. Новое обследование11 ноября успешно получило HTTP-ответы официального сайта. Поэтому текущая причина неполноты — объект81920 байт по доступному URL, подтверждённый Range416, а не неприменённый сетевой черновик.

**Связанное исправление PDF:** `FILE_PROCESSING_TIMEOUT_MS=120000`, допустимый диапазон 1000–300000 мс. Настоящий 17-страничный PDF комплаенса повторно прошёл Linux-парсер за **10 707 мс**, исходный SHA сохранён. Это **не подтверждение выполнения на Windows**; полное выполнение на Windows этим замером не подтверждено. Подробнее — [REPAIR-PR5](../../../docs/real-content/REPAIR-PR5.md).
