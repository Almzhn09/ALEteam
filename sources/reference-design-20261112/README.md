# Источники дизайна по референсу

Снимки официальных страниц от 12 ноября 2026. HTML хранится как источник, не выполняется и не публикуется в качестве страницы сайта. Данные макета не считаются источником.

Главная подтверждает адреса внешних ссылок. Контактная страница связывает фото центрального здания с архивом; полная JPEG-копия и SHA находятся в основном реестре изображений. Сведения S05 имеют приоритет для контактов и часов. Крылова, 39 и старые часы не смешиваются с предоставленной версией.

Страница антикоррупции содержит старую графику; актуальность номера 1424 и бесплатности звонка отдельно не установлена. На главной показывается ссылка на опубликованный раздел комплаенса без номера и чужого логотипа.

Методическая страница `/ru/NamedContent?type=Method` дважды вернула HTTP 500 при свежей проверке 12 ноября. Переход убран из главной; остальные опубликованные внешние ссылки вернули HTTP 200.
