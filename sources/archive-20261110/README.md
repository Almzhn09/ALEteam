## Связанные файлы S09

Три ограниченных GET по точным ссылкам из DOCX вернули HTTP 200. Снимки — в `linked/`, URL/контрольные суммы/ответы — [linked-fetch.json](linked-fetch.json), машинные выгрузки — [linked-extraction.json](linked-extraction.json). В общих фондах 3755 непустых строк, в партийных318, в газетной таблице1468 строк с заголовками; это не число уникальных фондов или документов. Газетный файл внутри прямо указывает состояние на01.01.2018. Перечень газет — DOCX, общие и партийные фонды — XLSB. Подписи ссылок говорят «01.01.2026», имена XLSB — «2018г.», имя газетного файла — «1935–2017», подпись — «1935–2011». Это расхождения источника, не проверенная актуализация на 2026 год. Макросы и встроенные объекты не выполнялись. Массового обхода сайта не было.

## Извлечение и готовые черновики

Текст DOCX извлечён из абзацев и таблиц, внешние связи сохранены в manifest; XLS прочитан по всем листам; PDF с текстовым слоем — `pdftotext -layout`. Семь сканированных PDF (59 страниц) распознаны Tesseract `rus+kaz`, tessdata_fast с зафиксированными SHA из `scripts/setup-ocr.mjs`, 2200px, PSM 3. OCR обозначен по страницам и **не проверен человеком**: не использовать распознанные цены, реквизиты или имена как утверждённые сведения. Исходные изображения и таблицы остаются в оригиналах. TXT офицера прочитан отдельно. Подписи/печати не являются текстовым подтверждением OCR.

[Подготовленные данные](../../data/archive-20261110/README.md): 13 карточек филиалов с источником лист/строка и 18 запросов создания CMS-черновиков из исходных RU/KK текстов. Английские переводы не выдуманы. Это файлы подготовки, не загрузка в рабочую БД и не публикация.

Проверка сохранности: `node scripts/verify-archive-sources.mjs`. Для OCR: `npm run ocr:setup`. Для повторного извлечения использовать Python python-docx/xlrd, libarchive 13, pdftotext и Tesseract 5; исходные хеши и инвентарь позволяют проверить результат. Конвертация XLSB описана в отчёте связанных файлов. Нужная для сайта информация переносится через существующее согласование CMS, а не прямой вставкой закрытых приложений в публичный каталог.
