# Демокорпус ALEteam

`demo-corpus.json` — 20 оригинальных вымышленных материалов команды для хакатона. Это не копия государственного архива. Все записи помечены isDemo=true, содержат предупреждение в самом тексте, реквизиты, происхождение, дату подготовки и SHA-256 текста. Персональные данные реальных людей не используются.

Правообладатель оригинальных демонстрационных текстов — ALEteam; они предоставлены под CC0-1.0 (https://creativecommons.org/publicdomain/zero/1.0/). Для каждого материала указан этот статус. Прав на контент исходного государственного сайта это заявление не предоставляет.

Пять PDF создаёт seed из соответствующих оригинальных текстов: это демонстрационные листы, а не сканы исторических документов. Ради переносимости текст внутри PDF транслитерирован; исходный русский текст доступен в карточке и JSON. Подтверждённых сканов исходного сайта нет, их копирование не выполнялось.

Индекс поиска PostgreSQL формируется из title/description при seed. Запуск: `npm run db:seed`; повторный запуск не создаёт дубликатов и не заменяет реальные документы. Старые стандартные описания fixtures обновляются только при совпадении исходного описания и заголовка. Изменённые вручную описания сохраняются.

Для переноса реального корпуса после аудита A01 нужны разрешение/основание использования, проверенные метаданные, источник, права доступа и отдельный импорт с валидацией. Эти материалы нельзя выдавать за исторические сведения в презентации.
