# Источники и подготовленные пакеты Артура

- `places.json`:3 места, реальные источниковые утверждения об именах, варианты распознавания и неопределённость Алтая. Даты существования всех алиасов не достроены.2018 переименование города отличается от2019 регистрации филиала.
- `place-events.json`:9 событий — по3 на Усть-Каменогорск, Риддер и Алтай. У каждого фактическая строка/цитата/SHA-256 источника. Частичная дата остаётся частичной. Источники календарные/исторические, не изображения первичных архивных актов; это указано в dateBasis. Нельзя превращать календарное юбилейное описание в самостоятельно подтверждённый подлинник.
- `issues.json`:8 проверяемых проблем/разночтений. Для Курдакова оба языковых текста2025 содержат80 при1940 годе рождения (арифметически85), а не ранее ошибочно указанное KK85. Спорные события не включены в набор хронологий.
- `topics.json`:7 редакционных тематик с RU/KK/EN labels для одинаковых ID в backend/frontend/ranking. Это исходная общая таксономия; добавление тем требует обновления общего набора, не отдельного списка в браузере.
- `fund-history-drafts.json`:1552 обычных +153 партийных группы буквальных номеров. Исторические названия сохранены построчно с исходными ячейками;523/65 групп имеют несколько строк. Все номера в выгрузке — строки; Unicode/учётные знаки не заменены. Описи/дела/документы не выдуманы; branchId ещё не сопоставлен.
- `fund-mapping-report.json`:точная карта полей, размеры, проверка цифровых номеров/строк без номера. Регистрирует дату2018/2026 как конфликт, raw Excel dates не конвертирует без проверки эпохи/формата. Этот пакет требует адаптера N-B03, не является существующим JSON staging-контрактом документов.
- `help-copy.json`:4 коротких шага и подсказки на3 языках. Необязательный запуск, пропуск/закрытие/повтор/возврат фокуса, без требования входа для помощи. Раздел «помощник» честно упоминает текущую авторизацию; тема/текст показываются только при capability displayPreferences.

Ничего из этого не импортировано в рабочую БД/не опубликовано. RU/KK исходные утверждения не заменяют редакционную/правовую приёмку; EN/KK авторские переводы требуют проверки. Нужен адаптер, стабильное сопоставление ключей, штатное согласование и актуальные права. Использовать sourceKey как происхождение, не как вымышленный официальный UUID/архивный шифр.

[Оригиналы и выписки](../../../sources/archive-20261110/README.md), [engine API](../../../docs/artur/discovery/ENGINE-API.md). Rebuild scripts перечислены в engine API; хеши цитат проверяются unit-тестом. Все3 скрипта работают на стандартной библиотеке Python и сохранённых JSON/текстах, дополнительных пакетов runtime не требуют.
