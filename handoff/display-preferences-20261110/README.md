# Заготовка настроек чтения для Алинура

Это **ранее начатая локальная работа**, переданная patch, не применённая к опубликованному дереву приложения. После просьбы пользователя о планировании новая реализация не продолжалась. Локальные изменения сохранены; другим агентам не нужно восстанавливать их по описанию.

`reading-preferences.patch` от базы `ca0c030` содержит sans-serif вместо засечек в заголовках/бренде, native «Вид сайта», систему/светлую/тёмную тему, текст100–150%, сохранение в cookie с SSR, мобильные переносы/прокрутку меню и удаление цветового перехода кнопок, который на мгновение снижал контраст. Внутри также browser-проверка, её npm script и уточнение селектора старого release-теста (150% просмотра документа отличается от150% текста).

Алинур: сначала сравнить со своей итоговой UI-версией; не создавать дублирующие настройки. На чистой совместимой ветке проверить `git apply --check handoff/display-preferences-20261110/reading-preferences.patch`, затем при принятии применить обычным `git apply ...` и закоммитить в своей frontend-ветке. Если аналогичные локальные изменения уже присутствуют, повторно patch не применять. `main` со старым планом не является базой для этого patch.

[manifest.json](manifest.json) фиксирует SHA базы, patch и пяти основных файлов. Ранее выполненная проверка **именно этих файлов**: production build/typecheck, i18n433/433,302 unit;28 display checks (в том числе24 сочетания ширины/темы/размера, без axe-нарушений) и13 release-сценариев; сводка двух последних suites — [validation-summary.json](validation-summary.json). [Исходный display-отчёт и4 скрина](../../docs/design-20261110/README.md). Данные синтетические, среда локальная с отдельной реальной PostgreSQL; ручной screen reader/настоящий browser zoom и EN UI не заявляются.

Это доказательство ранее проверенной заготовки, а не тестирование будущего фронтенда после применения/слияния. После интеграции Алинур обязан заново выполнить затронутые проверки и [приёмку отступов](../../задачи/ТЗ-2026-11-10/Отступы-и-проверка.md). Заготовка не реализует новые FEAT-01–08.
