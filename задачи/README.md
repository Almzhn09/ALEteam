## Что уже есть

Есть Next.js/PostgreSQL, базовый каталог/карточки/сканы, авторизация автора/модератора, серверное избранное, комментарии с модерацией, уведомления, RU/KK интерфейс, начальная шкала времени, собственная обученная модель с коротким диалогом, статический OCR/похожие документы и Docker с резервированием. Проверки и ограничения — в [отчёте по продолжению](../docs/REMAINING-VALIDATION.md) и [диалоге модели](../training/DIALOG.md).

Это основа, не закрытие всего ТЗ: нет полной CMS и семи штатных ролей, описей/дел, карты филиалов, цифровых коллекций/выставок/новостей, EN и многих требований эксплуатации. Тёмная тема сейчас определяется ОС; нужен пользовательский переключатель. Рабочий ИИ не заменяет официально проверенные сведения об архиве.

## Правила нового объёма

1. Сайт информационный. Не добавлять заявления, архивные запросы, заказы, официальные обращения, платежи или кабинеты их отслеживания. Личные списки открытых материалов разрешены.
2. RU/KK/EN, карта филиалов, выставки, новости, CMS, смысловой поиск и механизм аналитических рекомендаций — обязательные направления. Их прежние низкие приоритеты в старом плане заменены новым реестром.
3. Требование пользователя о собственном обучении модели сохраняется. Подключение внешнего LLM не требуется для локального основного пути; нельзя скрыто заменить собственный ИИ внешним сервисом.
4. Публичная карточка ограниченного документа и доступ к файлу — разные разрешения. Не открывать внутренние/персональные поля ради выполнения требования карточки.
5. Официальные адреса, координаты, названия, события, фото/права и переводы подтверждаются источниками/заказчиком. До подтверждения — явные демоданные и отмеченный блокер.

## Первый общий результат

Сначала согласовать источники, права и контракты. Затем пройти один работающий путь: **сотрудник создаёт материал → другой уполномоченный проверяет/возвращает → публикация нужной языковой версии → посетитель находит материал → помощник даёт проверяемый источник**. На той же CMS подключаются филиалы, выставки, новости и цифровая история.

Алинур параллельно готовит экраны и три языка по DTO Алимжана; Артур — контент и эталоны поиска/импорта. Затем проверяются карта/маршруты, аналитика качества, миграция, Lighthouse/WCAG/SEO, безопасность и общий показ. Сервер/домен для публичного HTTPS пока не предоставлены; ранее выбран Docker без хостинга. Подготовленная конфигурация не считается публичным развёртыванием.

Дата окончания хакатона и оставшиеся часы неизвестны — сроки не выдуманы. При сокращении объёма откладывается P2; оставшиеся обязательные требования явно перечисляются как незавершённые, а не объявляются выполненными.
