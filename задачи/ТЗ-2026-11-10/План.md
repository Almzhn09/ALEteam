## Приоритеты и рабочая основа

1. **P0: основное ТЗ и прямые требования пользователя.** Читаемый современный интерфейс для взрослых и пожилых, ручная светлая/тёмная тема, адаптивность, увеличение текста, простая навигация. Три языка, каталог, филиалы, CMS, безопасность и проверяемый ИИ остаются из основного ТЗ.
2. **P1: выбранные дополнения с готовыми источниками.** Контакты/структура/история, календарь, комплаенс, справочные страницы об услугах. Дополнения организаторов рекомендательные; название «необходимо» внутри S08 не превращает весь список в обязательный объём. Приоритет выбран командой по доступности данных и пользе для показа.
3. **P2: условные дополнения.** Погода, рейтинг, публичный счётчик, опрос, внешняя социальная лента и отдельная историческая карта — после основного сценария и только с данными/основанием. Не заполнять главную виджетами ради списка функций. **История места с хронологией FEAT-04 теперь выбрана пользователем и входит в объём; карта — необязательный способ отображения. Рекомендации, алиасы, объяснения, связи, подписки, исследовательский ИИ и помощь — по FEAT/COL.**

[Слова организаторов и границы услуг](Уточнения-и-дизайн.md). [Реестр источников S01–S09, реальные пробелы](../../sources/archive-20261110/README.md). [Подготовленные данные](../../data/archive-20261110/README.md).

На начало этой ревизии в `origin/frontend/alinur` доступен `f9dd377` от 7 ноября; сообщение пользователя о завершении Алинуром учтено, но новый итоговый SHA в GitHub не найден. Сначала принять доступный результат, не переписывать уже готовое.

Повторно не назначаем разработку foundation/catalog Алимжана, CMS-согласования/ролей, фильтров, RU/KK/EN проекций, разграничения публичности `32d585d`, загрузки PDF/PNG/JPEG `46eec22`, JSON staging/commit/rollback `cdf3721`, отчёта качества `14b6fb7`, последовательных уточнений ИИ `28a0a19`. ## Передача и порядок

- Алимжан начинает COL-B01 + N-B01/B02; Алинур — COL-F01/F06 и принятие заготовки N-F01; Артур после возобновления — COL-A01 + N-A02/A03. Подробная параллельная очередь — в Новые-функции.md. Каждый изменяет свою функциональную область и согласует DTO через код/документацию, не переписывает чужую ветку.
- Для каждой сдачи: SHA/ветка, изменённый контракт, рабочий сценарий, ошибка/недоступность, автоматическая проверка, актуальные ограничения. Закрытие пунктов только по этому результату.
- Оригиналы добавлены в GitHub как источники по разрешению пользователя. Отсутствие данных отмечается в реестре и UI; права на цифровые копии/персональные сведения не открываются из-за наличия файла в пакете.
- Полная новая CMS UI, EN UI, реальная миграция, прейскурант, носители языка и публичный HTTPS пока не объявляются завершёнными.
