# Отступы и визуальная приёмка — обязательно для фронтенда

Прямое требование пользователя: особенно внимательно делать отступы. Ответственный **Алинур**, независимая визуальная проверка — **Артур** при возобновлении своей части. «Похоже нормально» и отсутствие axe-ошибок не заменяют эту приёмку.

## Ритм и размеры

Использовать существующие `--space-*` из `src/app/globals.css`: 4/8/12/16/24/32/48/72px. Базовый шаг8px, 4px допустим для мелких внутренних элементов, 12px — для небольших связок. Новые смысловые токены связывать с этой шкалой; не множить случайные margin/padding, отрицательные отступы и выравнивание пробелами.

| Область | 360–767px | 768–1199px | От1200px |
|---|---|---|---|
| Общий контейнер | Поля16px | Поля24px | Поля32px, общий max-width1200px |
| Между крупными разделами | 32px | 48px | 48–72px по единому шаблону страницы |
| Внутренние поля карточки | 16px | 24px | 24px |
| Между карточками | 16px | 24px | 24px |
| Заголовок → вводный текст | 12–16px | 16px | 16px |
| Вводный текст → основное действие | 24px | 24px | 24–32px |
| Подпись поля → контрол | 8px | 8px | 8px |
| Между полями формы | 16px | 24px | 24px |
| Между кнопками | 12px | 12px | 12px |
| Иконка → текст | 8px | 8px | 8px |

Таблица — целевой договор для новых/обновляемых экранов, а не заявление, что текущий CSS уже полностью ему соответствует. Отклонение допускается осмысленно для просмотрщика/плотной таблицы и фиксируется в описании изменения.

- Один общий контейнер у шапки, основного содержимого и footer: совпадают левые края. Вложенный `.container` не должен удваивать боковые поля.
- В `flex/grid` применять `gap`, `min-width:0` и `minmax(0,1fr)`, перенос длинных названий/шифров. Количество колонок по доступной ширине, а не сжатием текста/кнопок до нечитаемости.
- Соседние кнопки не слипаются. Текст/бейдж/источник имеют собственный зазор; не соединять JSX-фрагменты без пробела/gap. Подсказки не прилипают к полям, заголовок — к соседней карточке.
- Кликабельные основные элементы минимум44×44px; высота карточки/поля растёт по тексту. Нельзя скрывать смысл фиксированной высотой, `overflow:hidden` или запрещённым переносом.
- При150% тексте и200% browser zoom сохраняются поля, доступные действия, перенос кнопок, порядок чтения. Большой текст не должен оставлять подпись в одном блоке, а связанную кнопку — в чужом.
- Sticky header/chat/toolbar не перекрывают контент/фокус. Мобильное меню имеет доступную прокрутку в пределах экрана, панель помощи/настроек помещается в viewport. Не «исправлять» overflow скрытием всей страницы по горизонтали.
- Объём главной ограничен: компактные рекомендации, ясные заголовки и «Все материалы». Расстояние между разделами помогает отличить поиск, рекомендации и новости; не превращать главную в бесконечную сетку.

## Матрица приёмки COL-F07

Проверить **главную, каталог, документ+объяснение/связи, историю места, помощник, подписки/уведомления и помощь/обучение**. Для административных новых форм использовать ту же систему отступов.

Обязательные сочетания:

1. 360/768/1440 CSS px, светлая/тёмная темы, базовый текст. Реальные длинные заголовки, казахские буквы и английские кнопки после EN UI.
2. 360px и1440px с150% текстом; отдельно200% **browser zoom**. Суженный viewport — только проверка reflow, не замена настоящему zoom/скринридеру.
3. Пусто/мало/много материалов, загрузка/ошибка/недоступный источник, помощь открыта, меню раскрыто, кнопка подписки в разных состояниях.
4. Клавиатура/видимый фокус/Escape/возврат фокуса, доступные подписи и порядок чтения. Автоматический axe плюс ручной осмотр.

К сдаче приложить screenshots desktop/mobile обеих тем для ключевых страниц, отдельный скрин150% текста и журнал проверок. Проверять геометрию bounding boxes: нет пересечений соседних действий; основной контейнер не выходит за viewport; одинаковые карточки имеют согласованные поля; минимальный зазор между соседними интерактивными элементами соблюдён. Если изображения/шрифты догружаются — снимок после их готовности.

В PR указать: применённые токены, исключения, ширины/масштаб/локали, найденные и исправленные проблемы. Не закрывать COL-F07 с обрезанными кнопками, двойными полями контейнера, слипшимися бейджами или незаполненной матрицей. Просмотр скриншотов — часть работы, сохранение PNG само по себе не проверка.
