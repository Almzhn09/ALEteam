# Артур — содержание для дизайна по референсу (V-A01…V-A05)

**Статус 12 ноября: V-A01–V-A05 реализованы и технически проверены в общей реализации Артура по поручению пользователя.** [Итог, доказательства и ограничения](../../docs/frontend-20261112/README.md). Исходное распределение ниже — история поручения, повторный запуск с нуля не требуется.

Общий план и разбор блоков: [Дизайн-по-референсу.md](Дизайн-по-референсу.md). Референс: [reference-home.jpg](reference-home.jpg). Ветка `artur/reference-content` от свежей `artur-full-tz-20261109`. Тексты и факты — только из предоставленных источников S01–S09, R01–R05 и официального сайта с сохранённой копией страницы.

| ID · приоритет | Задача | Критерий готовности / передача |
|---|---|---|
| **V-A01 · P0** | Карта блоков референса → реальное содержание: для каждого элемента (меню и его группы, три карточки, 15 пунктов «Разделы сайта», нижние карточки, ссылки подвала) решение «показываем из CMS / ссылка на официальный сайт с датой копии / заменяем на … / убираем» и причина. Файл `data/artur/reference-design/blocks.json` + краткое пояснение | Алинур получает его первым (до V-F04); у каждого «показываем» есть slug/API или URL источника; «Гостевая книга», «Метрические книги», «Погода», «Личные фонды» не превращаются в выдуманные разделы |
| **V-A02 · P0** | Изображения: заменить два обрезанных JPEG полными файлами (`npm run sources:images:refresh`, где сайт доступен), подобрать 2–3 фото для слайдов обложки и фото **именно этого** здания архива (если есть подтверждённый источник). Для эмблемы архива — источник и право использования или явное «нельзя». В реестре — подпись/alt RU/KK/EN, кредит, кадрирование. Публикация — штатным CMS-путём с проверкой вторым участником | В `manifest.json` у новых фото `complete_decode`; фото опубликованы как CMS-вложения; чужое здание не подписано как архив; без права эмблема не используется |
| **V-A03 · P0** | Сверка контактов и антикоррупционной полосы: адрес центрального архива и филиала (Крылова, 39 в референсе), телефоны приёмной/директора/заместителя/филиала, факс, e-mail, часы (S05: 8:00–17:00, читальный зал 9:00–16:00 — часы референса устарели). Номер 1424, слова «звонок бесплатный» и формулировка полосы — только по официальному источнику. Внести в структурные поля CMS «Контакты» новой редакцией | Каждое значение со ссылкой на источник и датой; расхождения референса перечислены; без подтверждения поле пустое, а не угаданное |
| **V-A04 · P0** | Тексты RU/KK/EN: заголовок и подзаголовок обложки и слайдов, кнопки, три карточки, полоса противодействия коррупции, названия групп меню и пунктов «Разделы сайта», подписи нижних карточек, подвал. Добавить в `data/artur/real-content-v2/ui-copy.json` (или новый раздел) | KK/EN — не машинный дословный перевод терминов; длина подписей помещается в карточки на 360/150% (сверить с Алинуром) |
| **V-A05 · P1** | Содержательная приёмка готового дизайна: нет ни одного выдуманного элемента референса, все факты/фото/номера совпадают с источниками, ИИ-помощник и поиск продолжают отвечать по тем же материалам; новые скриншоты для отчёта | Отчёт `docs/artur/reference-design/ACCEPTANCE.md` со списком проверенных блоков и остатков |

Передать Алинуру как можно раньше: V-A01 (обязательно до вёрстки блоков главной), первые тексты V-A04, решения по эмблеме и фото здания. Если нужно новое публичное поле API (например, отдельный телефон филиала в структурном виде) — согласовать с Алимжаном, не обходить CMS.
