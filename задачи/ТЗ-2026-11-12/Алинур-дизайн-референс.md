# Алинур — дизайн по референсу (V-F01…V-F06)

**Статус 12 ноября: V-F01–V-F06 реализованы и технически проверены в общей реализации Артура по поручению пользователя.** [Итог, доказательства и ограничения](../../docs/frontend-20261112/README.md). Исходное распределение ниже — история поручения, повторный запуск с нуля не требуется.

Общий план и разбор блоков: [Дизайн-по-референсу.md](Дизайн-по-референсу.md). Референс: [reference-home.jpg](reference-home.jpg). Ветка `frontend/alinur-reference-design` от свежей `artur-full-tz-20261109`. Обязательны [Отступы-и-проверка.md](../ТЗ-2026-11-10/Отступы-и-проверка.md), три языка, обе темы, «Вид сайта».

| ID · приоритет | Задача | Критерий готовности |
|---|---|---|
| **V-F01 · P0** | Визуальная основа: локальный WOFF2 засечного шрифта для заголовков (OFL, кириллица + Ә Ғ Қ Ң Ө Ұ Ү Һ І, лицензия в `public/fonts`), основной текст — текущий Noto Sans. Новые токены палитры (бумага, золото/охра, коричневый текст) для светлой и тёмной темы с контрастом AA. Собственные SVG-декоры: силуэт гор, казахский орнамент для углов/полос — `aria-hidden`, без растровых картинок | Шрифт не грузится с внешних серверов; все пары текст/фон ≥ 4.5:1 (крупный ≥ 3:1) в обеих темах; декор не перекрывает текст на 360/150% |
| **V-F02 · P0** | Шапка по референсу: название «Государственный архив ВКО и его филиалы» (эмблема — только после V-A02, иначе монограмма), меню с выпадающими группами Об архиве / Фонды / Услуги + Документы / Контакты; подчёркнутый активный пункт; поиск-иконка с раскрывающимся полем; RU/KK/EN; «Вид сайта», «Как пользоваться», ИИ-помощник — компактно. Мобильное меню | Клавиатура: Tab/Enter/Esc в выпадающих группах, фокус виден; на 360/150% шапка ≤ 2 строк, ничего не выходит за экран; группы взяты из карты V-A01 |
| **V-F03 · P0** | Обложка: крупный serif-заголовок с курсивной золотой строкой, подзаголовок, кнопка «Подробнее об архиве». 2–3 слайда на реальных опубликованных фото (через `slotVisual`/CMS-вложения) с подписью и источником; ручные стрелки и точки, **без автопрокрутки**; reduced-motion; без JS виден первый слайд | Слайды переключаются мышью, клавиатурой и касанием; у каждого фото alt/подпись/источник; нет фото — обложка остаётся текстовой с декором, а не с заглушкой |
| **V-F04 · P0** | Блоки главной: три карточки-перехода, антикоррупционная полоса (ссылка на «Комплаенс», номер — из V-A03), блок «Контактная информация» из CMS-страницы «Контакты» (адрес, телефоны, e-mail, часы, читальный зал, руководство, филиал), правая колонка «Разделы сайта» (только реальные/внешние с пометкой), нижние карточки (календарь и т.д. по V-A01). Существующие рекомендации и поиск сохраняются | Все значения берутся из API/CMS, ни одного захардкоженного телефона или часов; ссылка «на официальном сайте» помечена и открывается в новой вкладке; при пустом источнике блок скрывается, а не показывает заглушку |
| **V-F05 · P1** | Перенос стиля на внутренние страницы: заголовки разделов, карточки, справочники, поиск, страница материала, филиалы, справка, подвал с декором гор и реальными ссылками. Админка — только палитра/шрифты, без перестройки | Нет страницы со старой палитрой; таблицы/календари/постановления читаются на 360/150%; печать (Ctrl+P) без декора |
| **V-F06 · P0** | Приёмка: визуальная матрица CORPUS=real (360/768/1440 × RU/KK/EN × обе темы × 100/150% × 200%), axe, клавиатура, reduced-motion, Lighthouse ключевых экранов (медиана 3), скриншоты главной рядом с референсом, отчёт о расхождениях и их причинах | 0 находок матрицы и axe; Lighthouse ≥ 80; отчёт в `docs/frontend-20261112/` |

Не делать: погоду, гостевую книгу, метрические книги, автопрокрутку, сгенерированные/стоковые изображения, внешние шрифты/CDN, копии CMS-фото в `public/`.
