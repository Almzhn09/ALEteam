# ALEteam Local Query Model — обучение с нуля

Модель обучена командой на CPU, со случайной инициализацией. Готовые веса, готовый токенизатор, внешняя LLM и API-ключ не используются. Это небольшая специализированная авторегрессионная нейросеть, **не полноценная LLM общего назначения**. Она генерирует короткий поисковый запрос; текст ответа сайт собирает из реальных цитат после проверки доступа к источникам. Свободные исторические рассказы модель не генерирует.

## Что обучено

112 895 обучаемых параметров: линейный энкодер 1024→96, tanh, собственный словарь выходных слов, embedding 24, рекуррентный декодер RNNCell с 96 состояниями и выходной linear/softmax. На каждом шаге декодер использует предыдущее слово и генерирует следующее до EOS. Возможны многословные и составные запросы. Вход — нормированные частоты символьных n-грамм длины 2–5 с FNV-1a; это собственное кодирование, не готовый языковой энкодер.

Все параметры, включая embedding, энкодер и декодер, инициализированы заново (seed 2026) и оптимизированы Adam, learning rate 0.006, batch 128, gradient clipping 1, 120 эпох, teacher forcing/cross entropy. Выбирается checkpoint по validation loss; test не используется для выбора весов. Веса экспортируются в обычный JSON, инференс выполнен в TypeScript без Python/PyTorch в рабочем контейнере. Никаких сервисов или загрузки модели из сети при ответе нет.

## Данные и измерения

[train.py](train.py) содержит вручную заданные русские/казахские тематические варианты и шаблоны: пять тем документов, восемь справочных тем и «нет ответа». Это синтетические учебные данные ALEteam, CC0-1.0. Модель обучается маршрутизации вопросов, **не учит исторические факты из 20 демодокументов**. Демо-каталог и справки используются отдельно при поиске и составлении цитат.

Фактически использованные данные — [data/router-train.jsonl](data/router-train.jsonl), [validation](data/router-validation.jsonl), [test](data/router-test.jsonl). Ранее подготовленные 720 примеров выбора цитат заменены этим набором для выбранной архитектуры.

| Набор | Примеры | Точные совпадения с целевой последовательностью |
| --- | --- | --- |
| Train | 2915 | 2915 |
| Validation | 204 | 191 |
| Test | 204 | 204 |

Шаблоны вопросов разделены между частями; темы и тематические слова общие. Это лёгкая проверка переформулировок на известном словаре, не независимая проверка понимания языка. Казахские формулировки требуют носителя. Точный список неудач validation и все предсказания сохранены. Высокий softmax score не является гарантией правильности или надёжной оценкой уверенности.

[Отчёт обучения](report.json) содержит loss по эпохам, seed, время реального обучения, число параметров, SHA-256 начальных весов, конечного JSON и фактических датасетов. [Веса](models/query-model.json). Обучение занимает примерно десятки секунд на 5 CPU этой среды; это соответствует малому масштабу задачи, а не обучению большой языковой модели.

[Проверка полного помощника](grounding-evaluation.json): 63/63 подготовленных сценария через обученную модель, PostgreSQL и сборку ответа. Даты и точный архивный шифр обрабатываются структурированно, доступ и вредоносные инструкции проверяются сервером. Поэтому этот результат оценивает весь помощник, а не одну нейросеть. Набор составлен ранее при разработке; его вопросы исключены из обучения по точному совпадению, но он также не является независимым бенчмарком. Сырые предсказания модели в report.json включают ошибки на атаках — их блокирует отдельная серверная защита.

## Воспроизведение

Для обучения нужны Python 3.12 и CPU PyTorch, GPU не требуется. Из корня репозитория:

```sh
python -m venv .local/model-env
.local/model-env/bin/python -m pip install --extra-index-url https://download.pytorch.org/whl/cpu -r training/requirements.txt
npm run train:local
npm run evaluate:local
npm test
```

Установка требует сети; само обучение и инференс выполняются локально. В управляемой среде сохранять системные proxy/CA и TLS; не отключать проверку сертификатов. Повторное обучение перезаписывает отслеживаемые артефакты — изменения подлежат ревью. Для evaluate:local нужна подготовленная демобаза; тесты API требуют отдельной TEST_DATABASE_URL с суффиксом _test.

PyTorch 2.6.0+cpu — библиотека обучения, не предобученная модель. Точные воспроизводимые веса могут зависеть от версии библиотек и вычислительной платформы; сохранён SHA-256 конкретного обученного артефакта. JavaScript проверяется против Python на всех 204 тестовых предсказаниях, включая вероятности.

## Подключение

В приватном окружении сервера установить `ASSISTANT_MODE=local-model`, оставить ASSISTANT_SERVICE_URL пустым. Новые setup-команды и Docker Compose используют этот режим. Модели OpenAI и ключи не нужны. Для существующего Docker-стенда после сборки образов:

```sh
docker compose --env-file deploy/.env -f deploy/compose.yaml up -d --no-build --wait app
```

На странице помощника ответ имеет метку «Локальная модель ALEteam», API возвращает mode=local-model. Переключение на retrieval остаётся доступным для сравнения; автоматического скрытого перехода на правила при ошибке локальной модели нет. Поиск не принимает неизвестные сгенерированные команды: разрешены только известные темы/справки, остальные дают отсутствие ответа. Ни текст документа, ни вопрос не исполняются как код.

Для жюри: показать train.py, запуск обучения, loss и SHA-256, затем вопрос «Кітапхана туралы мәлімет керек», метку режима, источники, неизвестный вопрос и отклонение prompt injection. Честная формулировка: «собственная небольшая нейросеть генерации поисковых запросов, обученная с нуля, плюс поиск по БД и ответы с цитатами». Соответствие конкретным правилам хакатона подтверждает организатор; эта работа не заявляется большой LLM или моделью свободной беседы.

## Проверка внедрения

Production build и проверка типов прошли. Пройдены 200 модульных тестов и 20 HTTP-тестов, включая отдельный запуск с пустыми ключами провайдера. Хеш весов в Docker tools совпал с артефактом обучения. [Реальный браузерный показ](local-model-ui.png) и [результат проверки](runtime-proof.json) получены на обновлённом Docker-стенде. Повтор браузерной проверки: `node --env-file=deploy/.env scripts/check-local-model-ui.mjs` (нужны Chromium и действующие приватные демопароли). GitHub Actions дополнен evaluate:local, но его выполнение здесь не подтверждено. Main и опубликованная облачная среда не менялись.
