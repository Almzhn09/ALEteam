# Технический черновик политики доступа

Этот пресет позволяет разрабатывать API до TZ-A02 Артура. Он не заменяет подтверждение уполномоченным сотрудником архива и не подтверждает юридическое соответствие. Фактические данные и переводы ещё не получены.

| Пресет | Разрешения по умолчанию |
|---|---|
| SUPERADMIN | Все 12 известных прав, включая назначение ролей |
| SITE_ADMIN | Все, кроме `staff.roles.manage` |
| EDITOR | Читать/писать/проверять/публиковать контент, читать каталог |
| ARCHIVIST | Читать/писать каталог и контент |
| BRANCH_ADMIN | Управлять своим филиалом, читать/писать его каталог и контент |
| CONTENT_MODERATOR | Читать и проверять публикации |
| ANALYST | `analytics.read`; API отчётов пока нет |

Точный источник: [staff-role-presets.json](../../data/staff-role-presets.json). Пресеты настраиваемы через API: названия и набор известных прав можно менять, можно создать дополнительную роль. Назначение содержит филиал либо null (весь сайт); полномочия нескольких назначений объединяются без переноса права в чужую область. BRANCH_ADMIN требует филиал. Глобальные staff.*, settings.manage, audit.read не назначаются в области филиала. Последнего активного глобального управляющего ролями нельзя отключить, лишить права или удалить назначение.

AUTHOR и MODERATOR существующих комментариев не предоставляют CMS-права. Первого администратора создаёт одноразовая CLI-процедура, затем сотрудники создаются через авторизованный API. Публичной регистрации нет. Пароли хеширует Better Auth; получение/смена чужого пароля API не предусмотрены.

Публикация требует отдельного проверяющего, даже для администратора. Технически проверяющий с content.publish может затем опубликовать материал; заказчику нужно подтвердить разделение обязанностей. Источники и права обязательны для неучебных материалов; правильность источника проверяет человек. isDemo=true по умолчанию. Текст хранится как plain text: фронтенд обязан выводить его текстом без HTML-инъекций.

`STAFF_IDLE_TIMEOUT_SECONDS` задаёт idle timeout 60–86400 секунд, временное значение по умолчанию 1800. Проверка на каждом защищённом запросе, запись активности не чаще 30 секунд. Деактивация удаляет все сессии аккаунта. Это технический вариант до подтверждения срока заказчиком. Cookie/session Better Auth сохраняет собственный максимальный срок жизни.

Аудит хранит входы сотрудников и административные изменения без паролей, cookies, SQL и тел публикаций. Причины решений хранятся отдельно и доступны с правом content.read в области материала. Сроки хранения, резервирования, удаления аккаунтов/аудита, восстановление доступа и окончательная матрица требуют решения TZ-A02/B11. Новая аналитика, геолокация и сторонние счётчики пока не включены.

Сайт информационный: комментарии не являются официальными обращениями. Заявления, заказы, оплата и их отслеживание не добавляются.
