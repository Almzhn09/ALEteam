# Состояние заготовки интерфейса при передаче плана

Настройки чтения/шрифт были подготовлены локально до паузы; в этой публикации переданы **[patch для Алинура](../../handoff/display-preferences-20261110/README.md)**, а не изменения рабочего приложения. Нельзя считать новый опубликованный HEAD уже содержащим «Вид сайта». Все новые функции рекомендаций/подписок/историй/объяснений/обучения пока описаны задачами.

Четыре снимка сделаны ранее с проверенной заготовкой, реальным локальным production Next.js/Chromium и отдельной PostgreSQL, на **синтетических демоматериалах**:

- [Главная, светлая тема](01-home-light.png).
- [Главная, тёмная тема и125% текста](02-home-dark-large.png).
- [Мобильная360px, настройки и150% текста](03-mobile-reading-settings.png).
- [Мобильная KK, крупный текст и открытое меню](04-mobile-kk-large.png).

[Отчёт](report.json) содержит фактическое время снятия UTC, baseCommit и SHA-256 проверенных файлов; время UTC в JSON — машинные данные.28 display checks включают24 сочетания360/768/1440px × light/dark ×100/112.5/125/150%, сохранение URL/SSR/cookie, системную тему и KK. Скриншоты показывают заготовку, не новое наполнение официальными материалами и не итоговый редизайн.

После принятия patch новые экраны и отступы проверяются заново по [обязательной матрице](../../задачи/ТЗ-2026-11-10/Отступы-и-проверка.md). Полная EN UI, носитель языка, ручной screen reader и настоящий200% browser zoom не подтверждены этими снимками.
