# Каталог: редактирование, публикация и поиск

Второй серверный этап Алимжана, ветка `backend/alimzhan-catalog-workflow`. Дополняет [CMS API](../cms/API.md). Все маршруты ниже имеют префикс `/api`, cookie Better Auth, no-store и прежнюю проверку Origin для изменений. Контракты без серверных импортов: [`src/contracts/catalog.ts`](../../src/contracts/catalog.ts); прежний CatalogQuery теперь расширяет CatalogFilters.

## Права и область

| Маршрут | Право | Область |
|---|---|---|
| GET /admin/catalog/{funds,inventories,cases,documents} | catalog.read | Филиал фонда |
| GET /admin/catalog/{kind}/:id | catalog.read | Филиал фонда |
| POST /admin/catalog/{kind} | catalog.write | Филиал фонда |
| PATCH, DELETE /admin/catalog/{kind}/:id | catalog.write | Филиал фонда |
| POST /admin/catalog/documents/:id/restore | catalog.write | Филиал фонда |
| POST /admin/catalog/documents/:id/revisions | catalog.write | Филиал фонда |
| PATCH /admin/revisions/:id | catalog.write для архивной редакции | Филиал фонда |
| POST /admin/revisions/:id/transition → IN_REVIEW | catalog.write | Филиал фонда |
| transition → APPROVED/CHANGES_REQUESTED | content.review + catalog.read | Филиал фонда |
| transition → PUBLISHED/ARCHIVED | content.publish + catalog.read | Филиал фонда |
| GET /admin/revisions/:id/events | catalog.read | Филиал фонда |
| GET /admin/notices | Собственные уведомления + catalog.read | Область соответствующего документа |
| GET /documents, GET /documents/:id | Публично | Только опубликованные карточки/переводы |

Филиал фонда, фонд описи/документа и опись дела не переносятся через PATCH. Для исправления структуры требуется отдельный контролируемый перенос/импорт, не замена ID в произвольной форме. caseId документа можно изменить в согласуемой RU-редакции внутри того же фонда. Глобальное назначение охватывает старые фонды без филиала; назначение на один филиал не предоставляет глобальную область.

## Иерархия и корзина

POST сохраняет прежние форматы: фонд `{branchId,number,name,description}`, опись `{fundId,number,title}`, дело `{fundId,inventoryId,number,title}`. Номера — строки, `0007` и `7` различны. Номер фонда уникален внутри филиала, описи — внутри фонда, дела — внутри описи.

GET /admin/catalog/cases/:id → `{item:{...,updatedAt}}`.
PATCH /admin/catalog/cases/:id `{expectedUpdatedAt,number?,title?}`; для описи те же поля, для фонда number/name/description. Хотя бы одно поле обязательно. Передавать точное updatedAt из последнего ответа; устаревшее значение даёт 409 STALE_CATALOG. Неизвестные поля/параметры запрещены.

Чтобы правка названия не обходила согласование, изменения/удаление узлов блокируются, если в **этом фонде** есть опубликованный документ либо редакция IN_REVIEW/APPROVED. Это намеренно консервативное правило первого варианта; сначала снять публикации/вернуть редакции на доработку. DELETE пустого узла `{expectedUpdatedAt}` удаляет его; FK запрещают удаление узла с детьми, включая ссылки архивных/удалённых карточек.

Документ удаляется мягко: DELETE /admin/catalog/documents/:id `{expectedUpdatedAt}`. Опубликованный или проверяемый документ сначала нужно снять/вернуть с проверки. История и файлы сохраняются, обычный список исключает корзину. `GET /admin/catalog/documents?includeDeleted=1` включает её, прямая служебная деталь доступна по правам. POST /:id/restore `{expectedUpdatedAt}` восстанавливает закрытую карточку и не публикует её. Удалённая карточка не редактируется/не согласуется до восстановления.

## Архивная редакция

POST /admin/catalog/documents:

```json
{
  "fundId":"<fund-id>",
  "caseId":"<case-id>",
  "reference":"DEMO-0007-0001-0003-01",
  "title":"Учебная карточка",
  "description":"Оригинальный учебный материал, не архивное свидетельство.",
  "year":1930,
  "yearTo":1940,
  "type":"PHOTO",
  "originalLanguage":"kk",
  "leafCount":2,
  "rights":"ALEteam CC0-1.0",
  "sourceNote":"Авторские учебные данные",
  "category":"Образование",
  "tags":["Книги"],
  "internalNotes":"Служебная заметка",
  "isDemo":true
}
```

201 `{item,revision}`: документ закрыт, цифровая копия запрещена, RU-редакция DRAFT создана атомарно. Клиент не задаёт isPublic/allowDigitalCopy при создании. Для isDemo=false обязательны sourceUrl или sourceNote; достоверность/права подтверждает сотрудник, API не проверяет их истинность.

GET /admin/catalog/documents/:id возвращает `{item}` с текущей основной записью, приватными заметками и `contentItem.revisions`, отсортированными по языку/версии. Служебный список содержит активные редакции в contentItem.revisions (статус/ID/версия/время), без полного тела каждой редакции.

Архивные редакции используют внутренний kind=ARCHIVE_DOCUMENT. Они не выдаются через публичный /content, не смешиваются со списком информационной CMS и не создаются через её общий POST. Для ссылок выставки используйте **documentIds** с ID документа, не contentIds с ID его внутренней редакционной сущности.

PATCH /admin/catalog/documents/:id допускает **только** `{internalNotes,expectedUpdatedAt}`. Заголовок, даты, права, доступ к копии и остальные публичные поля меняются через редакцию:

- POST /admin/catalog/documents/:id/revisions `{locale:"ru",payload:{...полный снимок метаданных...}}`.
- PATCH /admin/revisions/:revisionId `{expectedUpdatedAt,payload:{...полный снимок...}}` только в DRAFT/CHANGES_REQUESTED.
- Для новой карточки сначала завершите существующую начальную редакцию. Вторую незавершённую редакцию того же языка API отклоняет.
- Старый публичный снимок остаётся доступен, пока следующая редакция не утверждена и не опубликована.

RU payload содержит title,description,rights,sourceUrl/sourceNote,authorName,organization,locality,storageLocation,accessConditions,category,tags,reference,caseId,year/yearTo,type,originalLanguage,leafCount,allowDigitalCopy. fundId/isDemo/internalNotes/status/authorId туда не передаются. Пустые необязательные текстовые поля передаются как null, не пустой строкой. Tags до 20, повторы без учёта регистра/NFKC запрещены.

Шесть состояний/переходы и обязательная причина — как в CMS. Проверяет другой сотрудник. При переходе публикации проекция каталога, язык, история и уведомления обновляются одной транзакцией. 409 STALE_REVISION означает, что нужно перечитать редакцию. Конкурирующие правки дают один успех и один конфликт, не тихую перезапись.

Для старой карточки первое POST /:id/revisions создаёт внутреннюю редакционную сущность без снятия её старой публикации. Миграция сохраняет старую RU-проекцию с revisionId=null; она не изобретает исторического проверяющего. Повторный demo seed не перезаписывает управляемые публикации и не восстанавливает снятую карточку.

## Языки и отзыв

Основная редакция этого варианта — RU, поскольку существующий корпус русский. KK/EN payload содержит **только переводимые текстовые поля**; нельзя поменять год, оригинальный язык, шифр, дело, количество листов или доступ к файлу через перевод. Сначала публикуется основная RU-карточка. Это техническое решение для существующей основы, не утверждённая языковая политика архива.

Публикация перевода не меняет RU. Отсутствующий/черновой перевод: деталь даёт 404, список — 0 результатов. availableLocales содержит только опубликованные языки, подмены нет. originalLanguage остаётся языком оригинала, locale — языком представления.

Перевод привязан к версии основного источника. При новой RU-публикации ранее опубликованные переводы архивируются, проверяемые/утверждённые возвращаются в CHANGES_REQUESTED, авторам приходят SOURCE_CHANGED. Черновик остаётся закрытым; для повторной отправки его нужно обновить по новому источнику и заново согласовать. Старая approved-редакция не может переопубликовать перевод устаревшего источника. Ошибка CATALOG_SOURCE_CHANGED — 409.

Снятие KK/EN оставляет RU открытой. Снятие RU закрывает документ и цифровые копии во всех языках, удаляет публичные проекции переводов и сохраняет историю. Возврат из корзины не возвращает публикацию. Новая публикация требует обычного согласования.

## Поиск и безопасная карточка

GET /documents поддерживает совместимые q/fundId/type/yearFrom/yearTo/sort/page/pageSize и новые фильтры:

| Параметр | Семантика |
|---|---|
| locale | ru по умолчанию, kk или en; только опубликованный перевод |
| branchId,fundId,inventoryId,caseId | Точный ID, все условия объединяются AND |
| fundNumber,inventoryNumber,caseNumber | Точное строковое совпадение, ведущие нули сохраняются |
| reference | Подстрока шифра без SQL wildcard |
| author,organization,locality | Подстрока опубликованного текста выбранного языка, регистр не важен |
| originalLanguage | Точный язык оригинала без учёта регистра |
| category,tag | Точное совпадение без учёта регистра |
| yearFrom,yearTo | Пересечение периода документа с запрошенным диапазоном |
| q | Полнотекстовый поиск опубликованных title/description/author/organization/locality/category, шифр/заголовок/теги; RU морфология + simple для KK/EN |

Сортировка year_asc/year_desc/title с ID как вторым ключом, pageSize 1–50, счётчик и список согласованы в RepeatableRead. `%`, `_`, обратный слеш в подстрочных фильтрах — литералы, SQL параметризован. Неизвестные/повторные параметры и неверный диапазон → 400.

Ответ `{items,total,page,pageSize,locale}`; элементы включают locale/availableLocales, реквизиты и выбранный опубликованный текст. GET /documents/:id?locale=en возвращает `{item}`, явный набор публичных полей. internalNotes, пароли, reviewerId, catalogBaseVersion и внутренний ContentItem не раскрываются. Открытая карточка с allowDigitalCopy=false доступна в поиске, но files=[], прямые файл/OCR дают 404. После снятия RU недоступны также комментарии/похожие документы; избранное и корпус ИИ исключают запись по isPublic.

Ограничения этапа: названия фонда/описи/дела пока канонические, без отдельных переводов; новые поисковые поля ещё не добавлены в формы фронтенда Алинура. Загрузки, TIFF/медиа, карантин/превью, массовый импорт/перенос структуры и аналитика — следующие задачи. Собственная модель не переобучалась; её существующий источник получает только опубликованную основную проекцию.
