## Новые доказанные сценарии

- Миграция и повторный seed сохраняют 20 старых карточек, файлы и RU-проекции; EN не появляется без публикации перевода.
- Правки фондов/описей/дел имеют область и timestamp; номера с нулями сохраняются, дубли/подмена родителя/удаление узла с детьми запрещены, пустые узлы удаляются.
- Новая карточка всегда закрыта; сервер отклоняет isPublic/allowDigitalCopy при создании, credential URL, дубликаты тегов и неучебный материал без происхождения. Посетитель/чужой филиал не изменяют каталог.
- Документ проходит шесть состояний, возврат и публикацию. Самопроверка/публикация без прав запрещены; модератор без catalog.read не утверждает архивную карточку. Через информационный /content или его POST нельзя получить/создать внутренний ARCHIVE_DOCUMENT.
- Все реквизитные фильтры работают совместно; `0007` не совпадает с `7`. Диапазон 1935–1936 находит документ 1930–1940. Литералы `%_`, SQL-подобный текст, повторные/неизвестные параметры не обходят условия.
- Переводы EN/KK проверяются отдельно, не изменяют RU/язык оригинала/дату. Черновик закрыт. Новая RU-публикация снимает устаревший EN, возвращает утверждённый KK на доработку, уведомляет автора; старый EN-черновик не отправляется без обновления по источнику.
- Следующий черновик не меняет живую версию. Прямой PATCH документа не изменяет заголовок/доступ. Приватные заметки не входят в проекцию/аудит. Одновременные правки дают 200/409.
- Корзина и восстановление сохраняют редакцию; восстановление оставляет документ закрытым. Удалённая карточка не редактируется до восстановления, чужой филиал не восстанавливает её.
- Утверждённая карточка без копии имеет files=[]; файл и OCR дают 404. После снятия RU закрыты деталь, комментарии, похожие документы и файлы, запись исключена из избранного/источников ИИ. Повторный seed не возвращает снятую публикацию.

Первый прогон выявил ошибки двух тестовых ожиданий: SQL-подобная строка в FTS может законно совпасть с обычным токеном; API помощника возвращает sources, а не внутренние sourceIds. Исправлены проверки литерального фильтра и реального контракта ответа. Финальный полный прогон новых сценариев — 12/12.

## Эксплуатация и границы

Dev-миграция применена после частного dump, сайт на 3000 запускается с новой схемой. Docker-стенд обновлён на 3100 после частного backup БД и файлов. На обоих адресах health/главная/каталог возвращают 200, сохранены 20 карточек и 7 ролей, анонимный /admin/me — 401. Учебные данные интеграционных тестов в общую БД не публикуются; новые администраторы не создаются автоматически. Дампы/секреты/логи остаются вне Git в .local.

Основной язык карточки в этом варианте RU; названия фондов/описей/дел пока канонические. Политика языка/сроков/доступа требует TZ-A02. Фронтенд новых форм и фильтров — Алинур. Реальные материалы, миграция старой базы и экспертная проверка переводов не получены. Загрузки/карантин/превью, staging импорта/экспорта, аналитика/нагрузка/HTTPS и независимая приёмка остаются следующими этапами.

Прежняя локальная модель не переобучалась, внешняя LLM не подключалась. Проверены авторизация и ответ mode=local-model на 3000 и 3100 (200, по 3 публичных источника). В существующей приватной .env предпросмотра отсутствовал ASSISTANT_MODE: добавлен local-model; секреты и конфигурационный файл не попадают в Git. Удалённый CI/публичный HTTPS/проверка другим участником не объявляются пройденными по локальным тестам.
