# Docker-стенд: проверка 8 ноября 2026

Выбранный пользователем объём: подготовить Docker-запуск, поскольку хостинга пока нет. Публичный сайт, DNS и реальный TLS-сертификат не создавались. Main и опубликованная облачная среда не менялись.

Подготовлены runtime-образ Next.js standalone, tools-образ для миграций/seed, PostgreSQL, named volumes документов/БД и необязательный HTTPS-профиль Caddy. Node, PostgreSQL и Caddy закреплены по проверенным registry digest. Приложение и tools работают как node/UID 1000. Роль archive_app не является суперпользователем; БД наружу не публикуется.

[Машинный отчёт — 7/7 сценариев](deploy-validation.json). Тест создаёт уникальные локальные проекты и очищает только свои контейнеры/тома; приватные копии и env-файлы в .local не публикуются. Повторяемая команда: `node tests/deploy.mjs` после сборки обоих образов. Проверки добавлены в CI; выполнение GitHub Actions здесь не подтверждено.

При первом запуске исправлены права чтения смонтированного CA для node и наличие fixtures, импортируемых TypeScript-скриптами. TLS не отключался. Для init-скрипта PostgreSQL установлены права чтения; Git фиксирует LF. При проверке перезапуска учтено, что синхронный Docker CLI задерживает обработку закрытия keep-alive соединения в тестовом Node-процессе: перед проверкой данных выполняется свежая HTTP-readiness проверка.

Это проверенный локальный пакет, а не подтверждение публичного развёртывания. Реальный домен/HTTPS, хостинг, LLM-ключ/модель и доступ для аудита исходного сайта отсутствуют. Ручная языковая проверка, скринридер и репетиция команды не имитируются тестами. Внешнее хранение копий и секретов настраивается владельцем будущего сервера; секреты не восстанавливаются из дампа БД.

Прототип использует JS/WASM-драйвер Prisma. Сообщение детектора native OpenSSL в slim-образе не обходилось отключением проверок: PostgreSQL, запись и восстановление проверены функционально. При смене toolchain повторить эти сценарии.

Команды запуска, копирования и восстановления: [deploy/README.md](../deploy/README.md).
