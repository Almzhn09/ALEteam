В ветке `features/artur-release-checks` объединены модули Артура и фронтенд Алинура (`f9dd377`). Это проверочная ветка; main и опубликованная версия среды не обновлялись. Прежние отчёты от 7 ноября остаются историческими.

## Сделано

- Проверен полный путь через настоящий интерфейс: поиск → фильтр → карточка → PNG и масштаб → избранное после перезагрузки → вход → помощник → комментарии → жалоба → решение модератора → скрытие/восстановление → выход с отзывом сессии.
- Исправлены ссылки справок: они открывают существующие разделы `/about#guide-*`, а не несуществующие документы. Режим retrieval/LLM/external показывается явно. Отмена клиентского запроса передаёт AbortSignal в fetch; она не обещает отмену уже выставленной провайдером стоимости.
- Исправлен подтверждённый обход фильтра: короткие слова вокруг разнесённого мата больше не поглощают проверку. Добавлены пунктуация, emoji-разделители, проверка HTML-сущностей и 50 дополнительных регрессионных тестов. Версия правил — ru-kk-rules-1.1.0. Неизвестный MODERATION_MODE направляет сообщения в очередь.
- Подготовлены пять собственных PNG-демолистов на русском, пригодных для просмотрщика. Манифест связывает хеш изображения с хешем исходного текста. Seed проверяет целостность до записи в БД. Это оригинальные учебные материалы, а не сканы государственного архива.
- Исправлен скролл казахских примеров чата на 360 px; добавлены вопросы интерфейса о «темір жол» и архивном шифре. Навигация больше не разрывает слова на десктопе; отступ липкой шкалы времени учитывает фактическую высоту шапки.
- Подготовлены [инструкция модератора](MODERATOR-RUNBOOK.md), [лист ручной языковой проверки](LANGUAGE-REVIEW.md) и [презентация PDF](PRESENTATION.pdf), 6 страниц. Владелец очереди по плану — Артур.

## Внешние условия, которые пока не выполнены

1. **A01.** Проверка 8 ноября: HTTP/HTTPS оригинала всё ещё блокирует proxy 403. Черновик разрешений для e-arhiv.vko.gov.kz сохранён, но применённая ревизия среды остаётся прежней. Без доступа нельзя достоверно заполнить официальные контакты, услуги и описание архива.
2. **I01/I03/I04.** Нет ARCHIVE_LLM_API_KEY и ARCHIVE_LLM_MODEL в текущем процессе. В черновике сохранены требование ключа для api.openai.com и предложение gpt-4.1-mini. Реальные доступность модели, тариф, бюджет проекта и работа провайдера не проверены. `npm run check:llm` сейчас завершается кодом 2 / MODEL_OR_KEY_MISSING. После применения настроек и безопасного ввода ключа запустить `npm run check:llm -- --run`: максимум один запрос, 500 выходных токенов, только собственный короткий текст. Это проверяет подключение, но не заменяет оценку качества реальной модели на корпусе.
3. **Q02.** Публичный HTTPS-стенд не предоставлен. Нужны URL/доступ к выбранному хостингу и повторный прогон там. Ручные скринридер, мобильная клавиатура и проверка носителем не имитируются автоматическими тестами.
4. **Q03 и ревью.** Автоматический сценарий прошёл; репетиция втроём и подтверждение другим участником ещё не проведены.

Сохранение черновика не применяет изменения и не публикует среду. Платформа сообщает requires_publish: для включения настроек пользователь должен проверить/сохранить их и опубликовать конфигурацию через настройки. Агент публикацию не выполнял. В коде по умолчанию остаётся локальный retrieval без платных вызовов.
