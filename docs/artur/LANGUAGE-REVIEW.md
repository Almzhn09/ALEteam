# Лист ручной языковой проверки

Автоматически проверено наличие 341 перевода интерфейса. Это проверка покрытия словаря, а не подтверждение корректного казахского языка. Ни носитель языка, ни скринридер в этом сеансе не участвовали. Поля подтверждения ниже намеренно не заполнены.

| Что проверить носителю | Где и какой результат ожидается |
| --- | --- |
| «Кітапхана туралы материалдар бар ма?» | Пример в чате на казахском находит библиотечные демоматериалы |
| «Темір жол туралы құжаттарды тап» | Пример находит документы о железной дороге; пробел в «темір жол» учтён |
| «Мұрағаттық шифр нені білдіреді?» | Открывается справка о шифре, ссылка ведёт к разделу помощи |
| «Дереккөздерден іздеу» / «LLM: дәйексөздерді таңдау» | Подписи режимов не должны обещать нейросеть в режиме поиска |
| Сообщения об отклонении и ручной проверке | Понятны, не обвиняют автора при неоднозначном совпадении |
| Казахские нарушения, омонимы и реальные способы обхода | Добавить разрешённые тестовые примеры без персональных данных; зафиксировать ложные блокировки и пропуски |
| Цитаты на языке оригинала | Не переводятся незаметно и не выдаются за проверенные исторические сведения |

Проверяющий, дата, замечания: **не подтверждено**.

Отдельный ручной прогон доступности: экранный диктор, последовательность фокуса в диалоге жалобы/просмотрщике/чате, увеличение интерфейса до 200%, реальная мобильная клавиатура. Автоматический axe не заменяет эти проверки.
