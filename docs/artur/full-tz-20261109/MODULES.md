# TZ-A06/A07/A08 — подготовленные границы интеграции

Модули TypeScript без внешних сервисов; проверка `node --import tsx --test tests/artur-full-tz.test.ts`. Они ещё не подключены к маршрутам, и это **не приёмка CMS/поиска/аналитики**.

- `cms-corpus.ts`: явная публичная проекция. Только PUBLISHED + APPROVED перевод нужного языка + metadataPublic + assistantAllowed. Никогда не читать privateText/filePath/комментарии/учётные поля. Данные запрашиваются заново; архивирование исключает источник без сохранённого кэша. Слой БД Алимжана обязан отфильтровать филиалы и поля до вызова. DTO — предложение к B05/B06/B09.
- `archive-search-intent.ts`: извлекает PHOTO, подтверждённый вариант названия города и десятилетие из RU/KK/EN. «Фотографии Усть-Каменогорска 1960-х» даёт PHOTO / ust-kamenogorsk / 1960–1969. Это правила, не измерение обученной семантической модели. Неизвестному месту не придумываются координаты. Окончательные ID мест задаёт B03, фильтры подключает B04. Нет поддержки произвольной географии/неоднозначных периодов; фиксированные тесты не доказывают полный смысловой поиск.
- `site-quality.ts`: отчёт по переданным агрегатам, а не сбор посетителей. Группы меньше 5 подавлены. Порог доли пустых поисков 30% — проектный, не согласованный с архивом. Вывод содержит период/основание/ответственного и requiresHumanReview. Идентификация людей и исходные поисковые строки не передаются. Вклад модели в этой версии равен нулю: правила статистики, не «обученный ИИ-аналитик». События и авторизацию предоставляет B10; до него A08 не закрывается.

Пример аналитики **синтетический**: catalog, 1–8 ноября, 20 поисков / 8 пустых / 2 страницы требуют проверки → проверить поиск/справку и передать редактору устаревшие страницы. Это не измеренная посещаемость сайта. Набор unit проверяет этот пример, подавление малых групп и невозможные счётчики.
