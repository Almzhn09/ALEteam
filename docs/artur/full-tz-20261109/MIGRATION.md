## Контрольный набор после реализации B03/B07/B08

1. Фонд `0007`, опись `01`, дело `0003/А`, документ `000009`: сохранить буквально, повторный импорт без дубля.
2. Такой же номер дела в другой описи: две записи; другая опись того же дела без решения — конфликт.
3. Отсутствующий родитель: ошибка с номером строки, без частичного публикационного состояния.
4. Одинаковый source_id с разным SHA-256: конфликт версии, без тихой перезаписи.
5. Неизвестный номер: пустой поиск; ошибочная дата/язык/отрицательное число листов: ошибка валидации.
6. Карточка публична, файл закрыт: метаданные из allowlist доступны, файл/его OCR/его текст в ИИ недоступны.
7. Фильтр «фото + Өскемен + 1960–1969 + фонд 0007 + опись 01»: все условия вместе, точное ожидаемое множество ID.
8. Изъятие публикации/перевода после индексации: исчезает из каталога и ответов, кэш не сохраняет копию.
9. Импорт → экспорт → повтор → rollback: сравнить нормализованные утверждённые поля/связи/хеши, а не только количество.

Контрольные количества настоящего экспорта и хеши его файлов **неизвестны**. Формат DTO и транзакции согласует Алимжан; этот документ не объявляет готовой новую схему БД. Прогон миграции по полному ТЗ пока BLOCKED.
