## Сценарий нового показа (A11, черновик)

Сотрудник A создаёт материал → рецензент возвращает и затем одобряет → редактор публикует отдельные RU/KK/EN-версии → посетитель находит документ → проверяет копию и пометку ограничений → открывает карту и выставку → задаёт вопрос своей локальной модели → видит источники → сотрудник снимает публикацию → источник исчезает из поиска/ИИ. Аналитик отдельно видит объяснимую рекомендацию по разрешённым агрегатам.

До готовности этого пути не записывать фиктивный ролик. Существующие слайды и записи относятся к прежнему прототипу. Резервную запись делать только с реально работающего нового пути, указав SHA/дату и ограничения. Репетиция втроём и независимый просмотр ещё не проведены; автоматический тест их не заменяет.

P2 A12–A14 не выполняются раньше обязательного P0/P1: нет подтверждённого исторического корпуса/геоданных, нового конвейера файлов B07 и приёмки A10. Чужие загрузки/закрытые копии не использовать для опытов.
