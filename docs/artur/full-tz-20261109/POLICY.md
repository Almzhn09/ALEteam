# TZ-A02 — проект политики, не юридическое утверждение

Для согласования архивом и реализации TZ-B01/B02/B05/B10/B11. Статус IN PROGRESS: функциональные предложения проверяемы, но полномочия/сроки не утверждены.

## Роли и области

Каждая операция требует права и branchId; интерфейс не является границей доступа. Запрет по умолчанию. Общий доступ — только явно выданное право scope=all; администратор филиала остаётся в своей области даже при подмене ID. Посетитель/прежний AUTHOR не получает служебные полномочия; прежний MODERATOR комментариев не получает CMS-публикацию автоматически.

| Пресет | Разрешения по проекту | Явный запрет |
| --- | --- | --- |
| Главный администратор | Настройка системы/назначение разрешений/отзыв сессий; аварийный доступ с журналом | Секреты в ответах/журнале; незаметный обход истории |
| Администратор сайта | Структура, публичные страницы, управление сотрудниками в выданной области | Самостоятельно выдавать себе root; читать значения интеграционных ключей |
| Редактор | Создать/править материал и перевод, подать на проверку, публиковать одобренное при отдельном праве | Утвердить собственную версию или перевод; публиковать неодобренную |
| Сотрудник архива | Фонды/описи/дела/файлы своей области, подготовить описания | Чужой филиал, системные настройки, автоматическая публикация |
| Администратор филиала | Сотрудники и материалы своего филиала в пределах выданных прав | Назначить глобальные права; служебные записи другого филиала |
| Модератор контента | Проверить/вернуть/одобрить чужую версию, снять публикацию с причиной | Проверить свою версию; права комментариев без отдельного разрешения |
| Аналитик | Разрешённые агрегаты и рекомендации | Публикация/персональные события/служебные документы/секреты |

Требуется решение заказчика: независимые люди или только разные полномочия; кто выдаёт/пересматривает роли; временная замена проверяющего. Консервативный проект требует другого человека. Владелец решения — руководитель архива/назначенный ответственный ИБ, пока не назначен.

## Публикации и переводы

DRAFT → IN_REVIEW → CHANGES_REQUESTED либо APPROVED → PUBLISHED → ARCHIVED. Возврат содержит причину; изменённая одобренная версия снова DRAFT и требует проверки. Архивирование и отзыв прав немедленно исключают запись из публичного поиска/помощника/карты/экспорта, а не только из меню. Новая редакция не заменяет опубликованную до отдельного одобрения. Публикация каждого ru/kk/en-перевода независима; наличие русского не выдаётся за английскую версию. Непроверенный перевод — только предпросмотр сотрудника с пометкой.

Метаданные/файл разрешаются отдельно. Проект allowlist ограниченной публичной карточки: id, одобренное название, шифр, тип, разрешённый период, публичные фонд/опись/дело и филиал, язык оригинала, общая причина ограничения. Только если каждое поле разрешено архивом. Не публиковать персональные имена/полные описания/точное место хранения/внутренние заметки/URL и OCR закрытого файла. Для ИИ — отдельно утверждённая публичная аннотация; закрытые копии и поля никогда не становятся цитатами. До утверждения карточка закрыта целиком.

## Данные и информационное назначение

Сайт не принимает официальные обращения, архивные запросы, заявки, заказы и платежи. Комментарий — обсуждение, не обращение; кнопки не обещают выдачу справки. Геолокация только по явному действию пользователя; при отказе ручной старт, без сохранения точной позиции. Длина прямой линии не называется длиной маршрута.

Аналитика по проекту: только агрегированные счётчики с периодом и минимумом группы 5, без email/IP/ID посетителя, точных координат, текста свободных запросов и комментариев; темы — из подтверждённого словаря. Малые группы подавляются. Данные аналитики не включаются в обучение автоматически. Разделять зарегистрированное нулевое событие и отсутствие измерения.

Сроки хранения не выдумываются: журналы входа/действий, сессии/неактивность, резервные копии, жалобы и аналитика ждут утверждения ответственным ИБ/юристом архива. До решения нет запуска внешнего сбора посещаемости; служебный журнал не удаляется автоматикой с придуманным сроком. Нужны основания обработки/уведомление/правила удаления, геопровайдер и договоры; этот документ не подтверждает соответствие законодательству.
