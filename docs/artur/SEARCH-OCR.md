# Двуязычный поиск, OCR и похожие документы

Расширение E03/E05 от 8 ноября 2026. Все исходные тексты и листы созданы ALEteam, CC0-1.0. Они вымышлены; исторические материалы государственного архива не загружались.

## Поиск и корпус

Сохраняются 20 оригинальных учебных документов, 5 PDF и 5 PNG. Корпус помощника расширен с четырёх до восьми авторских справок. Добавлены казахские тексты справок; новые темы — избранное, уведомления, OCR, проверка источников. Тексты находятся в [guides.ts](../../src/server/guides.ts). Переводы ожидают проверки носителем.

Поиск понимает дополнительные русские и казахские слова о читателях, учениках, выставках, благоустройстве, транспорте; несколько тем объединяются. Числовой диапазон включителен, «до/дейін» и «после/кейін» исключают указанный год. Точный DEMO-шифр имеет приоритет. Закрытые источники исключаются до ранжирования; подозрительные инструкции на RU/KK/EN не используются как данные для ответа.

Фиксированный [набор из 63 вопросов](../../tests/fixtures/search-bilingual.json): 32 русских, 31 казахский/латинский вариант, поиск по периоду, справки, неизвестные сведения и атаки. `npm run evaluate:search` сравнивает прежний разбор намерения и новый на одной текущей БД; обе версии используют одну безопасную сборку ответа. Это сравнение локального retrieval, не сравнение моделей LLM. Старый набор из 23 вопросов сохранён.

Проверка требует присутствия ожидаемых ID и правильного noAnswer. Дополнительные возвращённые источники не оценивались независимым человеком. Набор составлен во время разработки; это не независимый языковой бенчмарк.

## OCR

Используется локальный Tesseract 5 с официальными моделями rus/kaz из tesseract-ocr/tessdata_fast, тег 4.1.0, commit 65727574dfcd264acbb0c3e07860e4e9e9b22185. У моделей и движка лицензия Apache-2.0; модели загружаются в игнорируемый .local, их SHA-256 закреплены в [установщике](../../scripts/setup-ocr.mjs). TLS и проверка хешей включены. Сами модели в Git не добавляются.

Для воспроизведения нужны установленный Tesseract 5 и Chromium/Chrome, Node 24 и зависимости проекта. На Debian/Ubuntu вне управляемой среды Tesseract обычно устанавливается пакетом tesseract-ocr. Затем из корня:

```sh
npm ci
npm run ocr:setup
npm run evaluate:ocr
```

Если Chromium находится в другом месте, задать CHROMIUM_PATH. Скрипт использует пять существующих русских PNG и создаёт ещё два собственных казахских тестовых листа. Сеть на этапе распознавания не требуется; нет внешней OCR/LLM-передачи или пользовательской загрузки произвольных файлов. Эталон — текст, действительно отрисованный на листе, включая заголовок и реквизиты. Результат Tesseract не исправляется вручную.

[Сырые результаты, эталоны и измерения](../../data/ocr/results.json) содержат SHA-256 исходного изображения и текста, engine/model версии, среднюю engine confidence, CER и WER. CER — расстояние Левенштейна по Unicode-символам, делённое на длину эталона; WER — аналогично по словам. Регистр/пробельные переносы нормализуются, пунктуационные и буквенные ошибки остаются. Engine confidence не равна проверенной вероятности правильности.

На карточках первых пяти демодокументов есть раскрывающийся блок «Распознанный текст (OCR)». API /api/files/:id/ocr проверяет публичность файла/документа, границы хранилища и SHA-256 фактически выдаваемых байтов. При несовпадении или отсутствии подготовленного результата возвращает 404. Текст помечен как автоматический, неисправленный; оригинал не меняется и не подменяется распознаванием. В каталог/ответы ИИ этот непроверенный OCR автоматически не индексируется.

Прототип проверен только на чистой печати. Рукописи, низкое разрешение, наклон, потёртости, старые шрифты, реальные архивные страницы и человеческое исправление здесь не проверялись. Генерация отчёта — отдельная команда; в production-контейнере Tesseract не требуется, он выдаёт уже подготовленные проверяемые результаты.

## Похожие документы

GET /api/documents/:id/similar возвращает до пяти документов по TF-IDF/cosine общих слов заголовка и описания. Заголовок имеет больший вес; числа, служебные и почти повсеместные слова исключаются. Целевой документ и закрытые кандидаты не участвуют, порядок при равенстве стабилен. Прототип ограничен первыми 500 публичными кандидатами по ID; это не поиск по всему большому архиву.

На фиксированном учебном корпусе измеряется precision@3 по пяти известным темам. Высокое совпадение на повторяющихся учебных записях не переносится на реальные архивы. Рекомендация требует проверки описаний и источника; историческая связь автоматически не устанавливается. Результаты поиска и похожести: [search-bilingual.json](results/search-bilingual.json).
