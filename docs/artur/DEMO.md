# Q03 — сценарий показа и резервный вариант

Показ серверных функций рассчитан примерно на 5 минут. Это подготовленный сценарий, а не утверждение о проведённой репетиции втроём. Финальный интерфейс Алинура ещё не готов; его экран нельзя заменять технической страницей без объяснения зрителям.

## Подготовка

Из корня проекта выполнить команды запуска из ../DEPLOYMENT.md. Обязательны PostgreSQL, миграции, seed, `npm run build`, затем `npm run start`. Режимы для воспроизводимого показа без ключей: MODERATION_MODE=local, ASSISTANT_MODE=retrieval, внешние *_SERVICE_URL пусты. Проверить `/api/health` и наличие 20 демозаписей.

`npm run evaluate:artur` создаёт `.local/reports/artur-evaluation.json`. `npm run demo:artur` выполняет реальный поиск, входит демоавтором, задаёт три вопроса, создаёт три комментария и выходит. Он печатает только безопасные статусы/ID и сохраняет `.local/reports/demo-run.json`; ключи/пароли/cookie не выводит. Скрипт допускает только локальный адрес и действительно сохраняет комментарии. Не запускать много раз подряд: лимит 5 новых комментариев/минуту. Пароли не добавлять в презентацию или запись экрана.

`npm run capture:artur` сохраняет скриншоты только технической страницы на 360/768/1440 и результаты проверки клавиатуры/запросов. Нужен установленный Chromium, путь можно задать CHROMIUM_PATH. Это не аудит финального фронтенда. Чтобы использовать другой локальный порт, задать одинаковый BETTER_AUTH_URL для сервера и скриптов; demo также понимает DEMO_BASE_URL.

## Слайды и речь

1. **Проблема и границы (30 секунд).** Объяснить потребность в удобном поиске и понятных источниках. Исходный сайт из этой среды заблокирован прокси; конкретные дефекты его экранов не утверждать. Официального статуса проекта нет.
2. **Пользовательский путь (40 секунд).** Макет/готовый фронтенд показывает Алинур, когда он будет доступен. До этого показать архитектуру и API каталога, честно назвав стадию разработки. Вписать тему «библиотека», открыть demo-doc-01 и показать пометку ДЕМО.
3. **Источник и просмотр (40 секунд).** Показать реквизиты, права и demo-file-1. Объяснить, что это оригинальный вымышленный демолист, не исторический скан. Скачивание разрешено не у всех файлов.
4. **Помощник (60 секунд).** Спросить «Найди документы о библиотеке», открыть возвращённую ссылку и сопоставить цитату с текстом. Затем «Что такое архивный фонд?» и «Свидетельство Иванова». Показать разные источники и честное отсутствие ответа. Назвать текущий mode=retrieval. LLM показывать только после реального подключения/проверки; её вклад — выбор точных цитат, не выдумывание архивных фактов.
5. **Комментарии (60 секунд).** Обычное сообщение → PUBLISHED; тестовая ненормативная фраза → REJECTED; цитата → PENDING. Отклонённые тексты не показывать на публичном экране. Модератор открывает очередь, принимает решение с причиной, показывает журнал и восстановление. Показ кабинета зависит от фронтенда; API уже проверен тестами.
6. **Доказательства и ограничения (50 секунд).** Открыть свежий отчёт проверок. Уточнить, что наборы составлены разработчиками; отсутствие ошибок на них не гарантирует распознавание всех ругательств. Реальная LLM без ключа не проверена, официальный корпус не импортирован, публичный HTTPS-стенд и полная доступность интерфейса ещё требуют работы.

## Если показ прервался

- Отключён Интернет: встроенные поиск, фильтр и ответы из локальных источников продолжают работать при работающей БД; LLM не заявлять доступной.
- Нет БД/стенда: открыть сохранённый demo-run.json и скриншоты, явно подписав «записанный результат серверной демонстрации». Не выдавать их за живой интерфейс.
- Истёк лимит: показать сохранённый результат или подождать фактический Retry-After; не отключать защиту для презентации.
- Ошибка LLM: показать явную недоступность. Если решили перейти в retrieval, перезапустить сервер с режимом и назвать переключение зрителям.

Перед защитой провести репетицию втроём: Алимжан проверяет стенд и роли, Алинур — реальные экраны и мобильную навигацию, Артур — цитаты, ограничения, комментарии и рассказ. Это действие команды ещё не выполнено.
