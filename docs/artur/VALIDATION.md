Один из 16 HTTP-тестов запускает второе production-приложение без внешних stub-сервисов и проверяет встроенный фильтр, реальный поиск по PostgreSQL, справки, ссылки, закрытый документ и подмену инструкций внутри источника. Остальные тесты продолжают проверять внешний контракт, ошибки и ограничения бэкенда. Модульные проверки LLM используют искусственный ответ провайдера, без реального сетевого вызова.

На первом запуске вопросов было 18/20: словарь PostgreSQL дал разные основы для «музей»/«музея», а «станция» не совпала с «железной дорогой». Добавлено тематическое сопоставление заголовков; исходные ожидания не удалялись. После изменения — 20/20. На расширенных примерах модерации проверены дополнительные окончания и сочетания цифр с транслитом.

Наборы создавались в ходе разработки. Их результаты не являются независимым языковым бенчмарком и не гарантируют отсутствие будущих обходов. Нужны носитель казахского языка и дополнительные реальные примеры, которые можно легально обрабатывать.
