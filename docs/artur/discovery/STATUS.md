## Ограничения собственной модели

Веса query-model не заменены внешним API и не переобучены на закрытых/непроверенных документах. Новые алгоритмы явно маркируют dictionary/rules/TF-IDF/extractive/editorial, а не выдают эти результаты за новую обученную универсальную LLM. Исследовательский шаг — совет, не доказательство существования документа. Источник revalidate перед ответом обязателен даже при локальном ранжировании.

## Передача другим участникам

Алимжан: подключать **`arturDiscoveryEngines` из `src/server/artur-discovery/transport.ts`**, не переписывать движки; snapshot/видимость/DB и повторная проверка за транспортом. Reference-page-drafts и publication-plan — подготовка, не payload неизвестного endpoint. Алинур: использовать общие ResearchStep/ResearchAction, применять настройки чтения из прежнего handoff в своей UI-ветке; [отступы](../../../задачи/ТЗ-2026-11-10/Отступы-и-проверка.md) остаются обязательными.
