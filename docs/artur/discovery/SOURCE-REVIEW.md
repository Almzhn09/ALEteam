NULL филиала намеренно нельзя отправить как готовый запрос: оператор сопоставляет действующий Branch. Устойчивую идентичность фонда, действующее название и права ещё надо подтвердить.

Исходные3755/318 непустых строк дают1552/153 группы буквальных номеров;523/65 групп содержат несколько строк названий. Это **кандидаты истории названий**, не доказательство, что каждое отличие — переименование. Нет источника личных фондов. Нет описей/дел/отдельных документов и разрешённых цифровых копий — из таблицы они не создаются. Raw-значения и Excel epoch/формат сохранены; точные даты по серийному числу без формата не выведены.

[Газетный пакет](../../../data/artur/discovery/newspaper-holdings-drafts.json):1468 физических строк таблицы, из них2 заголовка и1466 строк хранения. Номера в первом столбце пусты; физическая строка — provenance, не постоянный архивный ID. [Реестр](../../../data/artur/discovery/showcase-review.json) содержит31 исходниковую редакционную единицу:18 CMS языковых запросов и13 профилей филиалов. Это соответствует диапазону20–50 кандидатов для содержательного показа, **approvedCount=0**. Число не означает31 подлинный архивный документ. CMS-адаптер действительно создаёт их DRAFT с SourceDraftBinding; повтор идемпотентен. Отдельно подготовлены9 событий/3 места/7 тем,26 фактических assertions и9 языковых редакций3 справочных страниц.

Порядок: автор сверяет текст/контакты/права → независимый сотрудник проверяет редакцию → публикация → получить текущие SourceRef → `prepare-artur-facts.ts` готовит тела PLACE/ALIAS/HISTORY → обычные DRAFT/проверка. Реальные ID назначает сервер. Изменённый родитель требует повторной проверки зависимых фактов. Исходник из Git не получает статус публичной проверенной CMS-записи автоматически.

Старые версии не объявлены действующим правом. Прейскурант OCR непроверен: оплата/калькулятор/заказ услуг не реализованы. На странице услуг — явные внешние eGov/Әділет, без имитации ведомственного обращения.

Погода/опрос/рейтинг/социальная лента не выбраны: без согласованного источника, политики и полезного сценария они перегрузят главную. Публичные просмотры — только импорт утверждённых агрегатов по явно включённой политике; нет вымышленной популярности или скрытого сбора. Уведомления о теме — только кабинет. Внешняя LLM/рассылка/хостинг/публичный HTTPS не считаются подключёнными без реальных настроек.

## Языки и ограничения объяснений

Исходные RU/KK редакции сохраняют язык; отсутствующий перевод показывается как оригинал. EN и новые короткие KK тексты/термины — редакционные черновики, носитель языка ещё не участвовал. Исторические подлинники целиком автоматически не переводятся. Объяснение — точные выдержки с источником/версией/UTF-16 смещением и редакционным словарём. Tesseract confidence — оценка распознавания, не вероятность правильности факта; скан/учётный номер/цены требуют сверки.

Воспроизведение: `python scripts/prepare-artur-curation.py`, остальные prepare/map-скрипты перечислены в [API](ENGINE-API.md). Для извлечения DOCX/XLSB и runtime интерфейса Python не требуется; подготовительные скрипты не выполняют публикацию и HTTP.
