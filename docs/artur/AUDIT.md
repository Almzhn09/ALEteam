# A01 — исходный сайт и ограничения исследования

Дата проверки: 7 ноября 2026 года (Asia/Almaty). Адрес пользователя: http://e-arhiv.vko.gov.kz/ru.

## Наблюдения

Обычные HTTP- и HTTPS-запросы к `/ru` через унаследованный прокси среды получили 403 Forbidden с заголовком server: envoy. Для HTTPS CONNECT отклонён до соединения с сайтом. HTML, список разделов и изображения исходного сайта не получены. Это блокировка доступа из среды, а не доказательство поломки самого сайта.

Сеть среды имеет enforced restricted policy; дополнительных разрешённых доменов нет. Для продолжения аудита необходимо разрешить `e-arhiv.vko.gov.kz` в настройках сети. Изменение сетевых настроек и публикация среды не выполнялись.

Нельзя подтвердить меню, услуги, контакты, состав фондов, языки, лицензию материалов и текущие мобильные проблемы. В проект не переносились персональные данные, реальные записи и сканы исходного сайта. Пока A01 имеет статус BLOCKED.
