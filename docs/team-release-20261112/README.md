## Публикация

В авторизованном Google Cloud Shell из актуальной общей ветки:

```bash
bash deploy/cloud-run/update.sh
```

При уже подключённой постоянной БД сохраняются её секрет и остальные переменные сервиса, меняется только образ. При отсутствии постоянной БД скрипт запросит прямой URL Neon скрытым вводом и затем подключит его через Secret Manager. Для скриптов Cloud Shell Node/npm/NVM не требуются: проверка URL выполняется Python 3. Сервис `saq-qurylys-api` не изменяется.

Доступа к GCP-учётной записи пользователя в среде агента нет: сборка образа в Cloud Build и публикация выполняются этой командой в его Cloud Shell. Локальная проверка кода не означает, что действующий публичный сервис уже обновлён.

Ограничения сохраняются: почта для подтверждения адресов и восстановления пароля не подключена; новое файловое хранилище для пользовательских загрузок пока временное. Neon сохраняет записи БД, исходные файлы восстанавливаются из репозитория.
