## Найдено в данных — передано владельцам

- **Артуру (R-A02):** `thematic-exhibition-altay.jpg` и `open-day-altay.jpg` в `sources/archive-visual-20261111/originals` обрезаны — ровно 81 920 байт, «premature end of JPEG». Сервер правильно отказывает в разборе; оба загруженных экземпляра отклонены проверяющим с причиной. Опубликовано только целое `archive-next-generation-ridder.jpg`. Нужны полные файлы; после этого их можно провести тем же путём (`tests/e2e/real-visuals.mjs`).
- **Алимжану:** `scripts/isolated-file-worker.mjs` на Windows не разбирал ни один PDF — пути pdf.js заканчивались `\`, а pdf.js требует `/` (`Invalid factory url`). Исправлено отдельной минимальной правкой пути; на Linux/Docker поведение не меняется. Прошу принять или заменить своей.

- **Алимжану (2):** на Windows-машине разработчика штатный `content:apply` нового пакета не проходит: `Аналитикалық анықтама СЖТІТ 2026.pdf` (13.9 МБ) разбирается изолированным процессом ~41 с, ещё два PDF — 18–20 с, а предел жёстко 20 с (`PROCESSING_TIMEOUT`). Для локальной базы предпросмотра предел был временно поднят только в рабочей копии и сразу возвращён — в коммиты не попал. Предлагаю сделать предел настраиваемым оператором (с прежним значением по умолчанию).

## Ограничения

- Lighthouse на этой машине шумит (рядом работают другие процессы): отдельные прогоны отличаются на 20–30 баллов, поэтому берётся медиана трёх. Это не замер хостинга.
- `/places` и «Для вас» используют факты/подборки Алимжана и Артура; персональные рекомендации проверены прежними тестами, не на реальном аккаунте.
- KK/EN интерфейса — черновики без носителя языка. Большинство материалов есть только на RU/KK — показываются оригиналом.
- Не проверены: настоящий browser zoom, скринридер, физический телефон.
