# Публичная регистрация — 12 ноября 2026

**Обновление передачи:** изменения этого отчёта уже отправлены в GitHub; [ветка и порядок интеграции](../GITHUB-HANDOFF-20261112.md). Формулировки о локальном состоянии ниже сохранены как история первоначальной проверки. Cloud Run из этого чата не обновлялся.

Добавлена страница `/register`, ссылка «Создать аккаунт» со страницы входа и `POST /api/auth/sign-up/email`. Используется существующая Better Auth и PostgreSQL. После создания аккаунта читатель автоматически входит и возвращается к безопасному относительному `returnTo`. Пароль подтверждается в форме, минимум 12, максимум 128 символов. Имя 2–80 символов, email нормализуется. Сообщение о закрытой регистрации удалено из страницы и неиспользуемых переводов; инструкции ИИ/справки обновлены на RU/KK/EN.

Пользователь получает только AUTHOR, без StaffAssignment. Роли, активация, признак подтверждения email и любые дополнительные поля публичного запроса запрещены строгой схемой. CSRF, HttpOnly-сессии и ограничение JSON 4096 байт сохранены. Better Auth ограничивает регистрацию 5 попытками за 60 секунд; дополнительный общий gate 10/60 применяется до хеширования. X-Forwarded-For не позволяет обойти общий лимит. Несуществующие auth-маршруты изменения профиля/ролей остаются закрытыми.

Email-подтверждение, почтовая доставка и восстановление пароля не подключались; адрес нового пользователя остаётся `emailVerified:false`. Интерфейс не обещает отправку письма. Обычная регистрация не создаёт служебный доступ.
