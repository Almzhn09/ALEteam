## P1-F3 готово

Дополнен существующий `app/loading.tsx`: глобальное краткое уведомление появляется сразу на обычном внутреннем переходе, ещё до ответа сервера, и выставляет `aria-busy` основному содержимому. При открытии назначения уведомление исчезает; другой переход не блокируется. Ссылки на файлы/API, внешние адреса, якоря той же страницы и модифицированные клики не запускают индикатор. Предусмотрена страховка от зависшего уведомления и режим reduced motion. Это обратная связь интерфейса, не заявление об ускорении сервера.
