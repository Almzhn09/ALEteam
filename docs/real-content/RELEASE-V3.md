# Алимжан — завершение серверных задач

Статус: **ВЫПОЛНЕНО**. Ветка `backend/alimzhan-release-v3`, основа интеграции `b85dfd2`. Принятые COL-B01–B06/N-B и R-B01–R-B05 переиспользованы; эта передача завершает обновление существующей установки. Изменений чужих веток нет.

## Результат

- Реальная копия рабочей БД обновилась с49 до53 языковых редакций в39 материалах. Сохранены49 прежних языковых привязок к ID материалов; новые редакции имеют историю. Проверены контрольные суммы аккаунтов, сессий, комментариев, избранного, подписок, предпочтений и назначений сотрудников до/после обновления.
- Реестр оригиналов расширяется17→21 без замены прежних bytes. Активный manifest обновляется атомарно; обе версии остаются в закрытой истории и резервной копии. Публичны27 связей файлов с текущими редакциями; прежние мастеры сохраняются при архивных редакциях.
- Повтор не создаёт новых публикаций/файлов/фактов/справочных строк. Редакторская правка, новая ручная редакция, отзыв и закрытый филиал требуют сверки. Замена редакции и публикация выполняются одной транзакцией; конкурентный отзыв не обходится. Прерванная обработка S06 заканчивает наложение измеренного OCR до публикации.
- `npm run deploy:upgrade -- --project EXISTING --env deploy/.env` сохраняет согласованную копию БД/files при остановленных app/jobs, передаёт её setup в отдельном read-only volume и проверяет identity/оба SHA. Ошибка до миграций возобновляет прежние контейнеры; после начала изменений сайт остаётся приостановленным с закрытой диагностикой. Restore выбирает записанные SHA runtime/tools и восстанавливает только новый проект.

Рабочая БД тоже обновлена до53 редакций:39 CMS-материалов,13 филиалов,1705 фондовых групп,1466 газетных строк,27 текущих вложений. Учебных публичных документов0. Пароли/роли действующих пользователей и прежний Docker-стенд сохранены; закрытые резервные копии не добавлены в Git.

## Границы

Полные закрытые source bundles, лист VPN и разработческое ТЗ не имеют публичного файлового route. Неизвестные данные/держатели/личные фонды не придуманы. OCR остаётся измеренным невычитанным распознаванием; машинная встречная проверка не является подписью госархива. Внешняя рассылка, хостинг/HTTPS и независимая юридическая/языковая приёмка не объявляются выполненными.

GitHub Actions обновлён, но удалённый результат не наблюдался; перечислены локальные проверки. Для восстановления старой версии нужны сохранённые runtime/tools images: дамп БД и files.tar не включают image layers. После аварийного завершения копирования source bundle оставшийся `.source-bundles.lock` снимается оператором только при остановленных setup-процессах.
