# N-B03/N-B04 — зависимости изолированных обработчиков

Добавлены точные версии в package-lock.json: @e965/xlsx 0.20.3 (npm-переиздание SheetJS CE; не устаревший xlsx 0.18.5), pdfjs-dist 6.5.438, sharp 0.35.5. pdfjs-dist использует свой optional @napi-rs/canvas для локального PDF preview. Новые зависимости нужны для реального разбора CSV/XLSX/XLSB и PDF/растров, не для DTO или замены собственной модели.

Проверены действительный roundtrip CSV/XLSX/XLSB со строкой 0007/буквенным шифром, полный raster decode sharp и загрузка PDF.js/Canvas в Node 24. npm audit --omit=dev: 0 известных advisories на момент установки. Это не антивирус и не гарантия отсутствия уязвимостей.

Обработчики вводятся следующими коммитами: отдельный процесс, ограничение входа/выхода, heap/timeout, никакого исполнения формул/макросов/JavaScript, отсутствуют cookie/DB/LLM-секреты в окружении процесса. Политика публикации/независимая проверка остаются в существующем API. Наличие зависимостей само по себе не означает готовую загрузку/preview/import.
