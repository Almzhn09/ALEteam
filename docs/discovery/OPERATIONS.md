# COL-B06 / N-B07–B09 — эксплуатация серверного расширения

Основа1592296, своя ветка backend/alimzhan-discovery-v1. Сначала миграции, затем приложение и workers **одной версии**; старую миграцию не править. 003 — факты/источники/предпочтения/outbox;004 — cursor и измерения;005 — file jobs/master→preview/оригиналы таблиц;006 — индексы очереди подписок и квоты preview. Резервное копирование перед применением на рабочей БД обязательно. В этой проверке рабочие dev/stand БД не мигрировались, использовались отдельная `_test` и уникальные Compose проекты.

## Процессы

```sh
npm run db:migrate
npm run uploads:inspect       # один ограниченный пакет файлов
npm run discovery:deliver     # один ограниченный пакет уведомлений
npm run archive:jobs          # периодический цикл; SIGTERM/SIGINT завершает работу
```

Docker runtime содержит standalone-приложение, offline parser и его pinned зависимости. Tools содержит миграции/CLI/источники. Старый базовый Docker workflow сохранён; `--profile workers` добавляет сервис jobs с теми же БД/files volume,512MiB/1CPU и restart unless-stopped:

```sh
docker compose --env-file deploy/.env -f deploy/compose.yaml --project-name ale-stand --profile workers up -d --no-build app jobs
```

Параллельные экземпляры не забирают один файл одновременно: CAS lease/token, max3 попытки. Уведомления защищены общей transaction lock и уникальностью подписка+материал. Воркер логирует только агрегатные количества/фиксированный код ошибки; cookie/тексты/пути/секреты не логируются. Отдельная rate limit и максимум2 дочерних парсера на процесс приложения. Восстановление исчерпанного lease не требует ручного SQL. Ошибку формата надо исправить новой загрузкой, retry не меняет объявленные SHA/размер/bytes.

## Backup / restore

Штатные `deploy/backup.mjs` / `restore.mjs` сохраняют весь PostgreSQL и volume files: новые факты, source bindings, исходные таблицы bytea, cursor/baseline/notices, jobs, неизменные мастеры, private quarantine и PNG derivatives входят автоматически.

Setup дополнительно сохраняет **закрытый** `files/source-bundles/archive-20261110` из переданного реестра: девять оригиналов, извлечения, linked-файлы и их provenance. `persist-source-bundle.mjs` не перезаписывает исходник; проверяет SHA существующих файлов, запрещает symlink/выход из storage root. Эти файлы не получают ArchiveFile/isPublic и не имеют публичного route. Поэтому исходный пакет входит в files.tar и не зависит от наличия исходников в runtime image. Несовпадение неизменного пакета останавливает setup, вместо тихого повреждения.

Backup имеет checksum manifest и0700 каталог; секретные env не копируются. Хранить backup как закрытые архивные данные, ограничить права/место/срок/шифрование по политике владельца. Restore только в **новый** проект/пустые volumes; одновременное использование изменяемых live volume и runtime/tools разных версий не допускается. Секреты задаются отдельно через закрытый env/настройки окружения, в Git не попадают. При обновлении dependencies повторить audit, сборку, parser/HTTP/Docker restore; исключения TLS недопустимы.

Включение `DISCOVERY_AGGREGATES_ENABLED=1` разрешает только импорт утверждённых агрегатов. Сбор событий и аккаунтная история остаются неподключёнными. Compose намеренно не включает flag по умолчанию. Реального провайдера, домена/хостинга, HTTPS-проверки извне нет: N-B09 — unconfigured, а не вымышленная интеграция. Погода/опрос/публичные счётчики не добавлены без N-A04.

## Нагрузка / отзыв

Новые чтения не кешируют разрешения/публичный текст между запросами; проверяют публикацию, открытость филиала/копии и актуальный source fingerprint. Внутри одного запроса разрешён краткий memoization. Indexes: факты kind/status/id и parent/status/id; subscriptions active/cursor/updatedAt/id; previews branch/date/id и author/date; jobs state/lease. Новые списки ограничены и имеют курсор/страницы; cursor не даёт доступа сам по себе.

Пределы измеряемого прототипа:200 фактов каждого вида,1000 карточек+1000 CMS для baseline, related ранжирует≤100 кандидатов; превышение полного корпуса503, а не ложный полный результат. Нет заявления о готовности на миллионах документов или о том, что3755 строк S09 —3755 документов. Оптимизация baseline для больших корпусов и Lighthouse≥80 остаются отдельными измерениями; UI/Lighthouse принимает Алинур/Артур.

Финальные результаты замера и проверок находятся в [VALIDATION.json](VALIDATION.json). Замер HTTP search/preview:12 последовательных запросов локального Docker, Node fetch с чтением всего тела,21 опубликованная **синтетическая** карточка. Это не браузерный Lighthouse и не SLA. Регрессионные browser проверки существующего интерфейса отдельно охватывают RU/KK,360/768/1440, обе темы; новые discovery UI не делались в серверной ветке.

## Проверки и ограничения приёмки

CI дополнен test:discovery после старых browser/evaluation suites (фикстуры очищают только `_test` БД). `npm test` включает реальный parser тест обоих XLSB, UTF-8 без BOM, Excel date/leading zeros, повреждённого PNG и PDF JavaScript, проверку цитат. Фикстуры не являются историческими фактами. Наличие workflow не объявляет удалённый GitHub Actions успешным до отдельного наблюдения run.

Проверки автоматические, статус IMPLEMENTED; независимую приёмку ACCEPTED выполняет Артур. Реальные source facts/переводы/достоверность контактов, N-A03 карта переноса, объясняющий engine и свободные формулировки ИИ требуют своей проверки. Рабочие данные сами не публикуются после merge.
