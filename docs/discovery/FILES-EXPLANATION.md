# N-B03/N-B04/COL-B03 — исходные файлы и разрешённый текст

## Загрузка и проверка

Штатные `/admin/uploads`, PUT `/:id/content`, review/publish сохраняются. UploadMime пока PDF/PNG/JPEG, максимум20MiB; TIFF/WebP/аудио/видео не объявлены подключёнными без согласованных материалов и отдельной приёмки.

После сверки размера/сигнатуры/SHA файл остаётся QUARANTINED и получает UploadInspectionJob. Одобрение дополнительно требует успешного разбора: PDF.js6.5.438 разбирает страницы/операторы, проверяет JavaScript/open actions/вложения/опасные аннотации и создаёт PNG первой страницы; sharp полностью декодирует изображение. Зашифрованный/неразбираемый PDF отклоняется. Права и независимый проверяющий обязательны, загрузка/парсер не публикуют копию автоматически.

Парсер работает отдельным процессом без DB/auth/provider secrets, без выполнения PDF JavaScript/макросов/формул. Лимиты:20 секунд, JS heap128MiB, не более2 одновременно на процесс приложения; PDF≤100 страниц/300000 операторов/1M извлечённых символов, растр≤16MP, превью≤2MiB и1000×1400. Это ограничения процесса и формата, **не ОС-песочница и не антивирус**. `antivirus=not-configured` возвращается честно. Docker jobs ограничен512MiB/1CPU; native-память парсеров не ограничена одним JS heap. Пограничные/большие архивные документы требуют отдельного профиля и приёмки, лимиты не обходить автоматически.

`npm run uploads:inspect` — один последовательный пакет≤20 задач, `archive:jobs` — повторение. Lease30s, токен владения, максимум3 попытки, сбой не оставляет опубликованную копию; последний истёкший lease становится FAILED. GET `/:id/inspection` — scoped catalog.read, без storageKey/leaseToken/base64. POST `/:id/inspection-retry` `{}` — только автор с catalog.write, QUARANTINED/FAILED, повтор ограничен числом попыток. Рецензент может скачать приватный оригинал существующим content endpoint. Сервер не исполняет команды/пути, переданные посетителем.

Публикация создаёт прежний master `upload-:id` с неизменными байтами и отдельный `preview-:id`: variant=preview,parentFileId=master,downloadable=false. `/documents/:id.files` дополнен variant/parentFileId, превью сортируются первыми; прежние поля сохранены. Публичная выдача проверяет текущий документ/филиал/права оригинала и SHA мастера/превью. Снятие мастера/карточки/разрешения копии или порча bytes прекращает выдачу. Превью не подменяет мастер.

## Текст и объяснение

GET `/files/:id/text` — только действующая разрешённая копия: прежний OCR с проверкой исходного SHA либо текст успешно разобранного опубликованного PDF. Возвращает id,text,sourceSha256,textSha256,engine,isOcr,corrected,fragments (реальная PDF page, offsets). Нет текста404; private path/произвольный URL не принимаются. Существующий `/ocr` сохраняет прежний контракт и не выдаёт PDF-текст за OCR. Новые сканы пока не получают автоматического OCR; распознанные демонстрационные сканы явно isDemo.

POST `/documents/:id/explanation` `{locale:"ru",sourceRevision?:"<sha256>"}`. Сначала без fingerprint; fingerprint связывает текущую опубликованную карточку, fileId и SHA байтов/текста. Повтор с устаревшей версией409 SOURCE_CHANGED. Не более5 файлов/12000 символов. Закрытая копия404 даже при открытой карточке. Нет разрешённого текста →no_text; нет переданного движка COL-A03 →unsupported с пустыми terms/citations. Это работающий транспорт, **не готовое генеративное объяснение**.

Статическая точка Артура: `discovery-engine-registry.ts`. explainFragments получает AuthorizedText после проверки прав; качество OCR reviewed/unreviewed/low, цифровой PDF not_applicable. Сервер проверяет форму/объём ответа, существование fragmentId и буквальное присутствие quote, пересобирает href/revision/page/offsets по входному тексту и повторно проверяет версию/байты перед выдачей. При low нет ready. Семантическая достоверность свободного summary/толкования требует отдельной оценки COL-A03; совпадение цитаты само по себе её не доказывает. Общий assistant/модель не переписывались.

## CSV/XLSX/XLSB поверх прежнего staging

POST `/admin/file-previews` — catalog.read+catalog.write области, JSON≤3MiB, bytes≤2MiB, base64 канонический. Например:

```json
{"branchId":"<existing-branch>","sourceNamespace":"approved-mapping-v1","format":"csv","base64":"<UTF-8 bytes in base64>","mapping":{"sheet":"Sheet1","startRow":2,"mode":"funds","columns":{"number":{"column":1,"representation":"display"},"name":{"column":2,"representation":"display"}},"defaults":{}}}
```

Реальный parser SheetJS CE0.20.3, не клиентская имитация. CSV только корректный UTF-8, без угадывания кодировки; XLSX/XLSB сверяет внутренний workbook.xml/bin. Лимиты:≤20 листов/10000 физических строк/50 столбцов/200000 ячеек,≤2MiB отображаемого текста, bounded output16MiB. SourceHash SHA-256, исходные bytes, raw/display/format/formula/type и физические номера строк сохраняются в приватной FileImportPreview. GET `/:id?page=1&pageSize=50` (≤100) отдаёт страницы источника/предпросмотра и полные counts; raw binary и пути не отдаёт. Формулы/ошибки в выбранных колонках требуют ручной сверки. `representation=display` сохраняет ведущие нули/буквы; raw выбирается явно. excel-year использует Excel date1904 и формат ячейки; фиктивный1900-02-29 помечается ошибкой, дата не выдумывается.

funds — только предпросмотр: одинаковые number/name отмечаются повтором, другое имя того же номера — POSSIBLE_HISTORICAL_RENAME_REQUIRES_REVIEW. Это кандидат на сверку, не автоматическое утверждение переименования/нового фонда. Из этих строк не создаются описи/дела/документы. POST `/:id/stage`409 MAPPING_REQUIRED.

documents — явные columns sourceId/fundKey/caseKey/title/description/reference/year/yearTo/type/rights и остальные допустимые metadata; defaults задаёт **оператор**, не ИИ. catalog передаёт существующий manifest-base `{isDemo,funds,inventories,cases}`. Стабильный sourceId — исходная колонка, не номер строки; новые ID из названия не строятся. Импорт≤100 документов, allowDigitalCopy=false, переводов не сочиняем. Все поля повторно валидируются прежним catalogImportSchema.

POST `/:id/stage` `{}` — только автор с правами области, атомарно вызывает **общую** stageCatalogImport (прежняя валидация/квота/аудит), возвращает batch id/state/digest/report/updatedAt. Повтор — тот же batch, repeated=true. Затем штатные /admin/imports validate/commit/rollback/export; отдельной публикации нет. DELETE незастейдженного preview — только автор, stage-привязку удалить этим API нельзя;≤20 незастейдженных preview на автора. Сроки хранения исходников/очистка committed provenance требуют политики оператора.

Оба настоящих S09 XLSB проверены:3755 и318 непустых строк, **не уникальных фондов**. Производственный перенос не выполнен: ждём N-A03 (колонки/исторические названия/источники/права/2018 против2026). В HTTP тесте только синтетическая полная карта проходит staging без автоматического commit/publication.

## Общая интеграция Артура

COL-A03 включён статическим registry: extractive выдержки/редакционный словарь с реальными цитатами и отказом, не генеративный свободный пересказ. Explanation дополнен `ocr` (used/quality/engine/optional confidence) из разрешённого текста; UI показывает предупреждение OCR сразу. Tesseract confidence нормирован0–1 и не является вероятностью исторической правильности. Native PDF не объявляется OCR. Суммарный текст/fragments ограничен12 000 символов, усечение явно сообщается, page/offset сохраняются. При другом языке UI разрешён fallback к существующему исходному языку, который указан у цитаты. Повторная проверка выполняется по фактически выбранной исходной локали.
