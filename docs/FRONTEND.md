# Фронтенд (A04, F01–F12, E04, E06)

**Актуальное оформление:** [референс, тёплая палитра, локальные Noto Serif/Sans, доступность и галерея](frontend-20261112/README.md). Карта меню/разделов — `data/artur/reference-design/blocks.json`.

Интерфейс Алинура поверх API v1 из [API.md](API.md). Клиент получает данные через same-origin `/api`, не содержит секретов и не импортирует `src/server`. Серверные компоненты главной и общего поиска используют те же серверные обработчики для первого ответа без пустого экрана. Серверные проверки прав, модерации и лимитов остаются единственной защитой — скрытие кнопок служит только подсказкой.

## Запуск

Обычный режим — с бэкендом и PostgreSQL по [DEPLOYMENT.md](DEPLOYMENT.md), затем `npm run dev`.

Режим моков (без БД, для вёрстки и показа макета): добавить в `.env.local` строку `NEXT_PUBLIC_API_MOCK=1` и запустить `npm run dev`. Ответы API имитируются в браузере по контракту (`src/lib/mock.ts`), над шапкой всегда видна плашка «Режим моков». Мок — не интеграция и не используется на стенде. Учётные записи мока: `author@example.test` / `moderator@example.test`, пароль `demo-password-123`. Слово «мат» в комментарии имитирует REJECTED, вопрос ИИ со словом «ошибка» — 503.

## Пользовательские пути

1. **Поиск:** главная → запрос → каталог (`/catalog?q=…`) → фильтры → карточка → «Назад» возвращает ту же выдачу и страницу.
2. **Изучение:** карточка → сканы (кнопки, клавиатура: ←/→, PageUp/PageDown, +/−, 0; полноэкранный режим) → «Открыть»/«Скачать» (скачивание только при `downloadable`).
3. **Избранное:** ☆ в выдаче или карточке → `/favorites` → переход или удаление; переживает перезагрузку.
4. **Обсуждение:** гость видит предложение войти → вход → комментарий → статус: опубликован / на проверке / отклонён (текст остаётся для правки) → жалоба на чужой комментарий.
5. **ИИ:** вход → вопрос (или «Спросить ИИ о документе» из карточки) → ответ с источниками-ссылками на карточки или явный «ответа не найдено».
6. **Модерация:** вход модератора → очередь → контекст (документ, жалобы, автоматическая причина) → решение с причиной → журнал; восстановление скрытых через вкладку «Скрытые».

## Состояния

| Экран | Загрузка | Пусто | Ошибка | Прочее |
| --- | --- | --- | --- | --- |
| Каталог | Скелетоны; при смене фильтров прежняя выдача приглушается | «Ничего не найдено» + сброс; страница вне диапазона → «К первой странице» | Сообщение и «Повторить» | Некорректные параметры URL отбрасываются с предупреждением |
| Карточка | Скелетоны, спиннер скана | Нет сканов — пояснение | 404 → «Документ не найден»; прочие — «Повторить»; ошибка скана | Плашка ДЕМО |
| Комментарии | Скелетоны, «Отправка…» | «Пока нет комментариев» | Сеть: повтор с тем же `Idempotency-Key` без дубля; 409 — новый ключ; 429 — время ожидания | REJECTED: причина PROFANITY, текст сохраняется; PENDING: «после проверки модератором» |
| ИИ | «Ищу в материалах…», отмена | Примеры вопросов | 503 — честная недоступность; 502 — ответ скрыт; 429 — лимит; повтор вопроса | `noAnswer` выделен; текст выводится только как текст |
| Модерация | Скелетоны | «Очередь пуста» | 401 → вход, 403 → «Нет доступа», 409 → очередь обновляется | Причина обязательна (3–500) |
| Избранное | — | Пусто + ссылка в каталог | Хранилище недоступно (приватный режим) | Очистка с подтверждением |

## Дизайн-система (F01)

Токены и компоненты — в `src/app/globals.css`: «бумажная» палитра с чернильным текстом и акцентом цвета морской волны, серифные заголовки, системный шрифт текста, отступы с шагом 4/8 px, радиусы, светлая и тёмная темы (`prefers-color-scheme`). Контраст: основной текст ≈14:1, вторичный ≥4.5:1, рамки полей и фокус ≥3:1. Компоненты: кнопки (primary/secondary/ghost/danger, высота ≥44 px), поля, карточки, уведомления, бейджи статусов и ДЕМО, хлебные крошки, пагинация, скелетоны, диалог. Внешние шрифты и CSS-фреймворки не подключались — без новых зависимостей и сетевых запросов при сборке.

## Языки (F12)

Русский и казахский интерфейс. Переключатель «ҚАЗ / РУС» в шапке сохраняет выбор в cookie `lang`, поэтому сервер сразу отдаёт `<html lang>`, заголовки и `<title>` на нужном языке. В коде строки пишутся по-русски через `t('…')` (`src/lib/i18n.ts`, клиентский контекст — `src/lib/lang.tsx`, серверный — `src/lib/i18n-server.ts`); казахский словарь — `src/lib/kk.ts`. Отсутствующий перевод показывается по-русски. Русские сообщения API переводятся по точному тексту.

Архивные материалы (названия, описания, фонды, права) не переводятся: они помечены `lang="ru"`, а в казахском интерфейсе карточка сообщает, что описание приводится на языке оригинала.

`npm run i18n:check` находит строки без перевода (сейчас 337 из 337 переведены). **Перевод черновой — его должен проверить носитель языка** перед тем, как считать F12 выполненной.

## Проверки

Браузерные сценарии лежат в `tests/e2e`. Они используют установленный Edge или Chrome и не входят в зависимости проекта:

```sh
npm i --no-save playwright-core axe-core@4.10.2
# моки: NEXT_PUBLIC_API_MOCK=1 npm run build && npx next start -p 3100
node tests/e2e/mock.mjs
# реальный API: БД + seed по DEPLOYMENT.md; тестовые заглушки сервисов Артура
node tests/e2e/stubs.mjs &
MODERATION_SERVICE_URL=http://127.0.0.1:4001 ASSISTANT_SERVICE_URL=http://127.0.0.1:4002 npm start
node --env-file=.env tests/e2e/reset-limits.mjs   # только локальная БД: сброс счётчиков лимитов
node tests/e2e/real.mjs && node tests/e2e/kk.mjs && node tests/e2e/axe.mjs light
```

`BASE_URL`, `ENV_FILE` и `BROWSER_CHANNEL` (`msedge`/`chrome`) переопределяют значения по умолчанию. Скриншоты — в `.local/e2e-shots/`. `stubs.mjs` — заглушки для проверки интерфейса, а не фильтр мата и не LLM.

## Наблюдения по API

- Лимит входа Better Auth общий для всех (5 попыток в минуту) — при показе несколько неудачных входов подряд блокируют вход всем. Интерфейс показывает понятное сообщение.
- Лимит ИИ — 10 вопросов в час на пользователя: на репетиции демо его легко исчерпать.
- Неверный формат ID документа даёт 400, интерфейс показывает его как «не найден».

## Вопросы к команде

- **Алимжан:** глобальный `X-Frame-Options: DENY` и `CSP: sandbox` на `/api/files` не дают встроить PDF в страницу, а в части браузеров sandbox блокирует встроенный просмотрщик PDF и при открытии во вкладке. Сейчас PDF открывается ссылкой «Открыть»; нужно решение (разрешить `frame-ancestors 'self'` для файлов или отдавать сканы как PNG/JPEG). В публичном списке комментариев нет `authorId`, поэтому кнопка жалобы видна и на своих комментариях — сервер решает сам.
- **Артур:** финальные тексты причин отклонения (сейчас в `src/lib/labels.ts`), реальные сканы в PNG/JPEG для A02, тексты для страницы «Об архиве» после A01.
