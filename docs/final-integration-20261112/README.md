## Уточнение цитаты о создании архива

Финальный просмотр реальных ответов обнаружил ошибку релевантности: вопрос «Когда был создан архив?» выбирал буквальное упоминание создания филиалов в 1963 году вместо первого абзаца о создании самого архива в 1940 году. В общем механизме **выбора цитаты** формы «создан», «основан», «образован» теперь оцениваются как один смысл. Источник, права доступа, ранжирование материалов и единственный принятый retrieval не менялись; текст цитируется дословно.

Регрессия на настоящем опубликованном тексте проверяет три формулировки вопроса, дату 1940 и неизменность цитаты; отдельный вопрос о Зайсанском филиале сохраняет его дату 1963. После исправления: 404/404 unit (добавлен один содержательный сценарий), 6/6 финальных backend + 2/2 R01, новая production-сборка, 22/22 HTTP. Проверка перевода и типов остаётся успешной; изменение серверное и не добавляет ключей интерфейса. Итоговая приёмка образа повторяется с этим исправлением.
